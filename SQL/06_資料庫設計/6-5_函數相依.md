# 6-5 函數相依 🎯

> 函數相依是正規化的基礎。這課比較抽象，但只要掌握定義，正規化就會很好懂。

## 定義

**函數相依（Functional Dependency, FD）**：寫成 **X → Y**，讀作「X 決定 Y」或「Y 函數相依於 X」。

意思是：**只要 X 的值相同，Y 的值就一定相同**。

- X 稱為**決定因素（Determinant）**
- Y 稱為**相依因素（Dependent）**

## 例子

選課表（學號, 姓名, 系所, 系主任, 課號, 課名, 成績）

| FD | 意思 | 成立嗎 |
|---|---|---|
| 學號 → 姓名 | 知道學號，就知道姓名 | ✅ |
| 學號 → 系所 | 知道學號，就知道他是哪個系 | ✅ |
| 系所 → 系主任 | 知道系所，就知道系主任 | ✅ |
| 課號 → 課名 | 知道課號，就知道課名 | ✅ |
| {學號, 課號} → 成績 | 知道誰修了哪門課，就知道成績 | ✅ |
| 姓名 → 學號 | 同名的人可能有不同學號 | ❌ |
| 學號 → 成績 | 一個學生有很多科成績 | ❌ |

💡 **類比**：函數 y = f(x)，一個 x 只會對到一個 y。

⚠️ FD 是根據**業務規則（語意）**判斷的，不是看目前的資料剛好如何。

## 🎯 FD 的分類（必考）

### 1. 完全相依 vs 部分相依

針對「左邊是**多個屬性**」的情況：

- **完全相依（Full FD）**：Y 相依於 X 的**全部**，少一個都不行
  - {學號, 課號} → 成績：只知道學號或只知道課號，都無法決定成績 ✅ 完全相依
- **部分相依（Partial FD）**：Y 只相依於 X 的**一部分**
  - {學號, 課號} → 姓名：其實只要學號就能決定姓名 → **部分相依**

**部分相依是 2NF 要消除的。**

### 2. 遞移相依（Transitive FD）

如果 **X → Y** 且 **Y → Z**（而且 Y 不決定 X），則 **X → Z** 是遞移相依。

- 學號 → 系所，系所 → 系主任 ⇒ 學號 → 系主任 是**遞移相依**
- 系主任是「透過系所」間接依賴學號

**遞移相依是 3NF 要消除的。**

### 3. 顯然相依（Trivial FD）

**Y 是 X 的子集合**，例如 {學號, 姓名} → 學號。永遠成立，沒什麼意義。

## 🎯 Armstrong 公理（推導 FD 的規則）

### 三個基本公理

| 公理 | 規則 | 例子 |
|---|---|---|
| **反身律**（Reflexivity） | 若 Y ⊆ X，則 X → Y | {A, B} → A |
| **擴增律**（Augmentation） | 若 X → Y，則 XZ → YZ | A → B ⇒ AC → BC |
| **遞移律**（Transitivity） | 若 X → Y 且 Y → Z，則 X → Z | A → B, B → C ⇒ A → C |

### 衍生規則

| 規則 | 內容 |
|---|---|
| **聯集律**（Union） | 若 X → Y 且 X → Z，則 X → YZ |
| **分解律**（Decomposition） | 若 X → YZ，則 X → Y 且 X → Z |
| **虛遞移律**（Pseudo-transitivity） | 若 X → Y 且 WY → Z，則 WX → Z |

⚠️ **左邊不能分解**：AB → C **不能**推出 A → C。

## 🎯 屬性閉包（Closure）：找出候選鍵的方法

**X⁺（X 的閉包）**：從 X 出發，利用所有 FD，能決定的**所有屬性**。

**如果 X⁺ 包含所有屬性，X 就是超鍵。**再檢查是否最小，就能判斷是不是候選鍵。

### 計算步驟

R(A, B, C, D, E)，FD：A → B、B → C、CD → E

求 {A, D}⁺：
1. 從自己開始：{A, D}
2. A → B，A 在集合中 → 加入 B：{A, B, D}
3. B → C，B 在集合中 → 加入 C：{A, B, C, D}
4. CD → E，C 和 D 都在 → 加入 E：{A, B, C, D, E}
5. 沒有新的可以加 → 結束

{A, D}⁺ = {A, B, C, D, E} = 所有屬性 → **{A, D} 是超鍵**

是不是候選鍵？檢查拿掉任一個：
- {A}⁺ = {A, B, C}（缺 D、E）→ 不是超鍵
- {D}⁺ = {D}（缺很多）→ 不是超鍵
- 所以 {A, D} 是**最小**的 → **候選鍵** ✅

### 💡 快速找候選鍵的技巧

- **只出現在 FD 左邊、從不出現在右邊**的屬性 → **一定**在每個候選鍵裡
- **兩邊都沒出現**的屬性 → 也**一定**在每個候選鍵裡
- **只出現在右邊**的屬性 → **一定不**在任何候選鍵裡

上例：A、D 只在左邊 → 一定在候選鍵裡；B、C 兩邊都有；E 只在右邊 → 不在。
先試 {A, D}，剛好就是候選鍵。

## 🎯 最小覆蓋（Minimal Cover）

> 考選部的正規化題常給一大堆 FD，先化簡成最小覆蓋，後面的分析會簡單很多。

**最小覆蓋**（又稱 Canonical Cover，正則覆蓋）：和原本的 FD 集合**等價**（推得出一樣的東西），
但**沒有任何多餘部分**的 FD 集合。

### 三個步驟

| 步驟 | 做什麼 | 怎麼判斷 |
|---|---|---|
| ① 右邊拆成單一屬性 | X → YZ 拆成 X → Y、X → Z | 分解律 |
| ② 去掉左邊多餘的屬性 | XA → B 中，A 是不是多餘的？ | 如果 **X⁺** 已經包含 B，A 就多餘，改成 X → B |
| ③ 去掉多餘的 FD | X → A 是不是多餘的？ | **先拿掉它**，用剩下的 FD 算 X⁺，如果還是包含 A，它就多餘 |

⚠️ 順序要先 ② 再 ③，反過來可能得到不是最小的結果。

### 例題

R(A, B, C, D)，F = { A → BC、B → C、AB → D }

**① 右邊拆開**：A → B、A → C、B → C、AB → D

**② 檢查左邊多餘屬性**（只有 AB → D 的左邊有兩個屬性）：
- 拿掉 B，看 A 能不能決定 D：A⁺ = {A, B, C, D}（A → B，再用 AB → D）→ 包含 D，**B 多餘**
- 改成 A → D

目前：A → B、A → C、B → C、A → D

**③ 檢查多餘的 FD**：

| FD | 拿掉它之後算左邊的閉包 | 結果 |
|---|---|---|
| A → B | A⁺ = {A, C, D}，沒有 B | 保留 |
| A → C | A⁺ = {A, B, C, D}（A → B → C）| **多餘，刪除** |
| B → C | B⁺ = {B}，沒有 C | 保留 |
| A → D | A⁺ = {A, B, C}，沒有 D | 保留 |

**最小覆蓋** = { A → B、B → C、A → D }

### 用途：3NF 合成法

有了最小覆蓋，可以直接分解出 3NF 的表（保證**無損**且**保留相依**，6-6 課）：
1. 左邊相同的 FD 合併：A → B、A → D 合成 A → BD
2. 每個 FD 變成一張表：R1(**A**, B, D)、R2(**B**, C)
3. 如果沒有任何一張表包含候選鍵，再加一張只有候選鍵的表（本例候選鍵是 A，已在 R1 中）

## 小測驗

1. R(A, B, C)，FD：A → B、B → C。下列何者可以推導得出？
   (A) B → A (B) C → B (C) A → C (D) C → A

2. R(A, B, C, D)，FD：AB → C、C → D。其候選鍵為？
   (A) {A} (B) {A, B} (C) {C} (D) {A, B, C}

3. R(學號, 課號, 姓名, 成績)，候選鍵為 {學號, 課號}，FD：學號 → 姓名。
   則「姓名」對候選鍵是？
   (A) 完全相依 (B) 部分相依 (C) 遞移相依 (D) 多值相依

4. F = { A → B、B → C、A → C }，下列何者是 F 的最小覆蓋？
   (A) { A → B、B → C、A → C } (B) { A → B、B → C } (C) { A → C、B → C } (D) { A → B、A → C }

5. F = { AB → C、A → B }，求最小覆蓋時，AB → C 的左邊可以化簡成？
   (A) A → C (B) B → C (C) 不能化簡 (D) 整個刪除

<summary>看答案</summary>

1. **(C)** 遞移律
2. **(B)**。{A, B}⁺ = {A, B, C, D}；A、B 只出現在左邊，一定在候選鍵中
3. **(B)** 只需要學號（候選鍵的一部分）就能決定姓名
4. **(B)**。A → C 可以由 A → B、B → C 遞移得到，是多餘的
5. **(A)**。A⁺ = {A, B, C}（A → B，再用 AB → C），已包含 C，所以 B 是多餘的
