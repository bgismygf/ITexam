# 6-8 關聯代數 🎯

## 觀念

**關聯代數（Relational Algebra）** 是關聯式資料庫的**理論基礎**，
用一組「運算子」對關聯（表）進行操作，結果還是一個關聯。

SQL 就是建立在關聯代數之上的。考試常考：**符號的意思**、**SQL 與關聯代數互相轉換**、**計算結果**。

## 🎯 基本運算（6 個）

| 運算 | 符號 | 意思 | 對應 SQL |
|---|---|---|---|
| **選擇**（Selection） | **σ**（sigma） | 選出符合條件的**列** | `WHERE` |
| **投影**（Projection） | **π**（pi） | 選出特定的**欄**（去除重複） | `SELECT DISTINCT 欄位` |
| **聯集**（Union） | **∪** | 兩個關聯的所有值組 | `UNION` |
| **差集**（Difference） | **−** | 在 R 但不在 S | `EXCEPT` |
| **笛卡兒積**（Cartesian Product） | **×** | 所有組合 | `CROSS JOIN` |
| **更名**（Rename） | **ρ**（rho） | 替關聯或屬性改名 | `AS` |

這 6 個是**基本運算**，其他運算都可以用它們組合出來。

💡 **記法**：
- **σ**elect **列**：σ 像 s，**s**election 選列 → WHERE
- **π**roject **欄**：π 像 p，**p**rojection 投影 → SELECT 欄位

⚠️ 注意命名的陷阱：**關聯代數的「選擇 σ」對應 SQL 的 WHERE，不是 SELECT！**
SQL 的 SELECT 對應的是「投影 π」。

## 🎯 衍生運算

| 運算 | 符號 | 意思 | 用基本運算表示 |
|---|---|---|---|
| **交集**（Intersection） | **∩** | 兩邊都有 | R ∩ S = R − (R − S) |
| **θ 合併**（Theta Join） | **⋈**<sub>θ</sub> | 依條件合併 | R ⋈<sub>θ</sub> S = σ<sub>θ</sub>(R × S) |
| **等值合併**（Equi-Join） | ⋈<sub>R.a=S.b</sub> | 條件只用 = 的 θ 合併 | |
| **自然合併**（Natural Join） | **⋈** | 用同名屬性等值合併，且同名屬性只留一個 | |
| **除法**（Division） | **÷** | 「全部都有」 | 見下方 |
| **左/右/全外部合併** | ⟕ ⟖ ⟗ | LEFT / RIGHT / FULL JOIN | |
| **彙總**（Aggregation） | **γ** 或 𝒢 | GROUP BY + 彙總函數 | |

## 寫法

```
σ_條件(R)                     選擇
π_屬性1,屬性2(R)               投影
π_name(σ_year=113(exams))      組合：113 年考試的名稱
```

### 範例：SQL ↔ 關聯代數

| SQL | 關聯代數 |
|---|---|
| `SELECT * FROM exams WHERE year = 113` | σ<sub>year=113</sub>(exams) |
| `SELECT DISTINCT subject FROM exams` | π<sub>subject</sub>(exams) |
| `SELECT DISTINCT subject FROM exams WHERE year = 113` | π<sub>subject</sub>(σ<sub>year=113</sub>(exams)) |
| `SELECT * FROM questions q JOIN exams e ON q.exam_id = e.exam_id` | questions ⋈<sub>questions.exam_id = exams.exam_id</sub> exams |
| `SELECT content FROM questions NATURAL JOIN exams WHERE year = 113` | π<sub>content</sub>(σ<sub>year=113</sub>(questions ⋈ exams)) |

💡 **轉換技巧**：SQL 由內往外對應
- FROM → 最內層的關聯（有 JOIN 就是 ⋈ 或 ×）
- WHERE → 套上 σ
- SELECT → 最外層套上 π

## 🎯 計算題重點

| 運算 | 結果的值組數 | 結果的屬性數 |
|---|---|---|
| σ(R) | ≤ \|R\| | 與 R 相同 |
| π(R) | ≤ \|R\|（去除重複） | 選取的屬性數 |
| R ∪ S | ≤ \|R\| + \|S\| | 與 R 相同（必須相容） |
| R − S | ≤ \|R\| | 與 R 相同 |
| R × S | **\|R\| × \|S\|** | **R 屬性數 + S 屬性數** |
| R ∩ S | ≤ min(\|R\|, \|S\|) | 與 R 相同 |

## 🎯 除法 ÷（較難，但常考）

**R ÷ S**：找出 R 中，**與 S 的「所有」值組都有配對**的那些值。

### 例子：找出「選修了所有必修課」的學生

選課 R(學號, 課號)：

| 學號 | 課號 |
|---|---|
| S1 | DB |
| S1 | OS |
| S1 | NET |
| S2 | DB |
| S2 | NET |
| S3 | DB |
| S3 | OS |

必修 S(課號)：

| 課號 |
|---|
| DB |
| OS |

**R ÷ S** = 修了 DB **而且** 修了 OS 的學生 = **{S1, S3}**

- S1 修了 DB、OS（還有 NET，多修沒關係）✅
- S2 沒修 OS ❌
- S3 修了 DB、OS ✅

**結果的屬性** = R 的屬性 − S 的屬性 = {學號}

### 用基本運算表示（了解即可）

```
R ÷ S = π_A(R) − π_A( (π_A(R) × S) − R )
```
意思：所有學生 − 「有缺修任何一門必修」的學生

### 用 SQL 表示：雙重 NOT EXISTS

「找出學生，**不存在**任何一門必修課，是他**沒有**修的」
```sql
SELECT DISTINCT r1.學號
FROM 選課 r1
WHERE NOT EXISTS (
    SELECT * FROM 必修 s
    WHERE NOT EXISTS (
        SELECT * FROM 選課 r2
        WHERE r2.學號 = r1.學號 AND r2.課號 = s.課號
    )
);
```

或用比較直覺的 GROUP BY 寫法：
```sql
SELECT 學號 FROM 選課
WHERE 課號 IN (SELECT 課號 FROM 必修)
GROUP BY 學號
HAVING COUNT(DISTINCT 課號) = (SELECT COUNT(*) FROM 必修);
```

💡 看到題目有「**所有**」「**全部**」「**每一個**」，就要想到**除法**。

## 關聯演算（了解即可）

除了關聯代數，還有**關聯演算（Relational Calculus）**：
- **關聯代數**：程序性（Procedural），描述「**怎麼**做」
- **關聯演算**：非程序性（Non-procedural），描述「**要什麼**」
  - 值組關聯演算（TRC）、定義域關聯演算（DRC）
- SQL 結合了兩者的特性

## 小測驗

1. 關聯代數中，用來選出符合條件之值組的運算為？
   (A) π (B) σ (C) × (D) ∪

2. 下列何者「不是」關聯代數的基本運算？
   (A) 聯集 (B) 差集 (C) 交集 (D) 笛卡兒積

3. `SELECT name FROM emp WHERE salary > 50000` 對應的關聯代數為？
   (A) σ<sub>name</sub>(π<sub>salary>50000</sub>(emp))
   (B) π<sub>name</sub>(σ<sub>salary>50000</sub>(emp))
   (C) σ<sub>salary>50000</sub>(emp) × π<sub>name</sub>(emp)
   (D) π<sub>salary>50000</sub>(emp)

4. R 有 3 個屬性、10 個值組；S 有 2 個屬性、4 個值組。R × S 有幾個屬性、幾個值組？
   (A) 5、14 (B) 5、40 (C) 6、40 (D) 6、14

5. 要查詢「修過所有課程的學生」，最適合使用哪一種關聯代數運算？
   (A) 聯集 (B) 交集 (C) 除法 (D) 投影
