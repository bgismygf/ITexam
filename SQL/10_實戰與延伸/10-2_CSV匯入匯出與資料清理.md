# 10-2 CSV 匯入匯出、資料清理 💼

## 觀念

工作上很常遇到：「這是同事整理的 Excel，幫我匯入系統」或「把查詢結果匯出給主管」。

**CSV**（Comma-Separated Values）是最通用的交換格式：純文字、用逗號分隔欄位，
Excel、所有資料庫、所有程式語言都能讀寫。

```
年度,科目,題號,題目
114年,計算機原理,1,關聯式資料庫中...
```

## 💼 真實世界的資料都是髒的

人工整理的資料一定會有問題。範例檔 [`data/新題目_待匯入.csv`](../data/新題目_待匯入.csv) 故意放了這些常見問題：

| 問題 | 範例 |
|---|---|
| 前後多餘空白 | `  關聯式資料庫中…  `、` A ` |
| 大小寫不一致 | `b`（應該是 `B`） |
| 全形字元 | `Ｃ`（全形，應該是半形 `C`） |
| 格式不一致 | 年度有的寫 `114年`、有的寫 `114` |
| 缺值 | 第 4 題沒有答案 |
| 重複資料 | 第 2 題出現兩次 |
| 不合法的值 | 答案是 `E`、配分是 `二` |

## 匯入的標準流程（ETL）

```
1. Extract 擷取   →  2. Transform 轉換/清理  →  3. Load 載入
   CSV 匯入               在 SQL 中清理、驗證          寫入正式資料表
   「暫存表」
```

**關鍵：先匯入「暫存表」（staging table），所有欄位都用 TEXT，不要直接匯入正式資料表。**
清理、驗證完成後，再寫入正式資料表。這樣：
- 髒資料不會因為型態或限制條件錯誤而匯入失敗
- 可以用 SQL 好好檢查和清理
- 有問題的資料可以挑出來退回給提供者

## DB Browser 匯入 CSV

1. `File → Import → Table from CSV file...`
2. 選擇 `data\新題目_待匯入.csv`
3. 設定：
   - **Table name**：`import_raw`
   - **Column names in first line**：✅ 勾選（第一列是欄位名稱）
   - **Field separator**：`,`
   - **Encoding**：`UTF-8`
4. 按 OK，然後 **Write Changes** 存檔

## DB Browser 匯出

| 要匯出什麼 | 方法 |
|---|---|
| 整張表成 CSV | `File → Export → Table(s) as CSV file...` |
| 查詢結果成 CSV | 在 Execute SQL 的結果表格上，選取後複製（Ctrl+C）貼到 Excel；或用結果區上方的按鈕存成 CSV |
| 整個資料庫成 SQL | `File → Export → Database to SQL file...`（9-6 課） |

⚠️ **Excel 開啟 UTF-8 CSV 中文變亂碼？**
用 Excel 的 `資料 → 從文字/CSV`，選擇編碼 `65001: Unicode (UTF-8)` 匯入；
或匯出時選擇「UTF-8 with BOM」。

## 常用的清理函數（SQLite）

| 問題 | 處理 | 函數 |
|---|---|---|
| 前後空白 | 去除 | `trim(x)` |
| 大小寫 | 統一 | `upper(x)` / `lower(x)` |
| 全形字元 | 取代 | `replace(x, 'Ｃ', 'C')` |
| 多餘文字 | 移除 | `replace(x, '年', '')` |
| 型態 | 轉換 | `CAST(x AS INTEGER)` |
| 空字串 | 轉成 NULL | `NULLIF(trim(x), '')` |
| 檢查是不是數字 | | `x GLOB '[0-9]*'`、`typeof(x)` |
