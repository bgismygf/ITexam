## 手寫 SQL 的準備方法

科目 B 不能用電腦，SQL 要寫在答案卷上：

1. **先在紙上寫，再到電腦驗證**：把上面 110、112、113 年的題目，用課程的資料表或自己建表練習
2. **寫完整的語法**：不要用 SQLite 特有的寫法。取前幾筆時，可以註明「MySQL 用 `LIMIT 5`，SQL Server 用 `TOP 5`」
3. **欄位別名和中文欄位**：題目常常要求輸出指定的欄位名稱，用 `AS` 對齊
4. **計算題寫出過程**：例如 B+ Tree 題要寫「樹高幾層 + 資料頁幾頁」，只寫答案會被扣分
5. **常考句型背熟**：
   - 多表 JOIN 後 GROUP BY 加總
   - `HAVING COUNT(*) >= n`
   - `ROUND(x, 2)` 計算欄位
   - 「全部都…」的關聯除法：`NOT EXISTS (... NOT EXISTS (...))`
