# 10-3 綜合專題：完成題庫系統

## 目標

把整套課程學到的東西整合起來，完成一個**真的能用來準備考試**的刷題系統。

## 刷題程式

執行 [`10-3_刷題程式.py`](10-3_刷題程式.py)（VS Code 按 ▶，或終端機 `python "10_實戰與延伸/10-3_刷題程式.py"`）：

```
========== 題庫刷題 ==========
  1. 隨機練習 10 題
  2. 錯題複習（最近一次答錯的題目）
  3. 練習還沒做過的題目
  4. 弱點分析報表
  0. 離開
```

⚠️ 作答紀錄會寫入 `data/exam.db` 的 `practice_log`。
目前 `practice_log` 裡的 10 筆是範例資料，正式開始刷題前，可以先清空：
```sql
DELETE FROM practice_log;    -- 記得 Write Changes
```

## 專題任務

先讀懂刷題程式裡的 SQL（程式最上面的 `SQL_` 開頭的變數），再完成下面的任務。
任務的 SQL 寫在 [`10-3_綜合專題.sql`](10-3_綜合專題.sql)，有參考答案。

| # | 任務 | 用到的觀念 |
|---|---|---|
| 1 | 依「章節」出題：只抽某一章的題目 | JOIN、參數 |
| 2 | 「間隔複習」：答對的題目，隔越久越該複習；選出「最久沒練習」的題目 | 彙總、MAX、ORDER BY |
| 3 | 模擬考：從每份考試各抽 2 題 | 視窗函數 ROW_NUMBER + PARTITION BY |
| 4 | 每日進度報表：每天作答幾題、答對率、累計題數 | GROUP BY、視窗函數累計 |
| 5 | 連續答對：找出「最近連續答對 2 次以上」的題目（代表已經熟練） | 視窗函數、CTE |
| 6 | （挑戰）把任務 1～5 加入刷題程式的選單 | Python |
