## 怎麼使用這份教材

每一課有兩種檔案：

| 檔案 | 用途 | 怎麼打開 |
|---|---|---|
| `.md` | 講義：觀念說明、重點整理 | 在 VS Code 打開，按 `Ctrl+Shift+V` 顯示排版後的畫面 |
| `.sql` | 練習：範例和練習題，附解答 | 用 **DB Browser for SQLite** 打開 `data/exam.db` 後執行（安裝方法見 0-3） |

純觀念的課只有 `.md`，沒有 `.sql`。第 10 單元另有 `.py`（Python 程式）。

**學習流程**：讀 `.md` → 執行 `.sql` 的範例 → 自己寫練習題 → 對解答

**執行 `.sql` 的注意事項**
- **一句一句執行**（游標放在該句，按 `Shift + F5`；多行的句子要整段反白後按 `Ctrl + Enter`）。
  如果按 `F5` 執行整個檔案，遇到第一個錯誤就會停下來
- 標示 `-- 預期錯誤` 的句子，**出現錯誤訊息是正常的**，是要讓你看違反規則時會發生什麼事
- 第 5 單元起會修改資料，練習都在 `my_` 開頭的練習表上進行，不會動到原本的題庫
- 解答放在每個 `.sql` 檔最下方的 `/* ... */` 裡；要執行解答時，反白那一句再執行

**標記說明**
- 🎯 考試重點
- 💼 工作常用
- 🎯💼 兩者都重要

**練習資料庫**：`data/exam.db` 是一個「國營考試題庫」，裡面目前是自編的範例題。
如果資料庫被你改壞了，執行 `data/建立題庫.sql` 就能還原（方法見 0-3）。
