# 4-3 相關子查詢 🎯

## 兩種子查詢

| | 非相關子查詢 | 相關子查詢（Correlated Subquery） |
|---|---|---|
| 子查詢是否用到外層的欄位 | 否 | **是** |
| 能不能單獨執行 | 可以 | **不行**（缺外層的值） |
| 執行次數 | **一次** | 外層**每一列都執行一次**（邏輯上） |

```sql
-- 非相關：子查詢自己就能跑
SELECT * FROM questions
WHERE score > (SELECT AVG(score) FROM questions);

-- 相關：子查詢用到外層的 q.exam_id
SELECT * FROM questions q
WHERE score > (SELECT AVG(score) FROM questions WHERE exam_id = q.exam_id);
```

## 範例：配分高於「該份考試」平均的題目

上面第二個 SQL 的意思是：對每一題，算出**它所屬那份考試**的平均配分，再比較。

執行過程（邏輯上）：
```
外層第 1 列：q.exam_id = 1 → 子查詢算出 exam 1 的平均 = 2.0 → 1.5 > 2.0？否
外層第 4 列：q.exam_id = 1 → 子查詢算出 exam 1 的平均 = 2.0 → 2.5 > 2.0？是 ✓
外層第 7 列：q.exam_id = 2 → 子查詢算出 exam 2 的平均 = 2.0 → 2 > 2.0？否
...
```

## 經典用法：每組中的最大值那一列

「每份考試中，配分最高的題目」：
```sql
SELECT q.exam_id, q.question_id, q.score
FROM questions q
WHERE q.score = (SELECT MAX(score) FROM questions WHERE exam_id = q.exam_id);
```

「每題最近一次的作答紀錄」：
```sql
SELECT * FROM practice_log p
WHERE p.answered_at = (SELECT MAX(answered_at) FROM practice_log
                       WHERE question_id = p.question_id);
```

這類「每組取第一名 / 最新一筆」的需求在工作上**非常常見**。
4-6 課的視窗函數會提供另一種（通常更好的）寫法。

## EXISTS 幾乎都是相關子查詢

上一課的 EXISTS 就是相關子查詢：
```sql
WHERE EXISTS (SELECT 1 FROM practice_log p WHERE p.question_id = q.question_id)
--                                                              ↑ 外層的欄位
```

## 💼 效能注意

- 相關子查詢「邏輯上」每列執行一次，資料量大時可能很慢
- 現代資料庫的最佳化器常常會自動改寫成 JOIN，但不一定每次都成功
- 遇到慢的相關子查詢，可以試著改寫成 **JOIN + GROUP BY** 或**視窗函數**

## 🎯 進階考題：「全部都…」的查詢（關聯除法）📌(B113、統計資訊 115)

看到題目有「**所有**」「**全部**」「**每一個**」，就是關聯代數的**除法 ÷**（6-8 課有理論）。
考題常指定寫法，兩種都要會。

### 例題（115 年國營統計資訊類改編）

```
Students(Sid, Sname, Tname)     學生（學號、姓名、導師）
Takes(Sid, Cno, Score)          修課（學號、課號、分數），主鍵 {Sid, Cno}
Courses(Cno, Ctitle, Tname)     課程（課號、課名、授課教師）
```

**找出「修了 Jessica 老師所教的所有課程」的學生學號與姓名。**

這題的「除數」不是固定清單，而是**子查詢**：Jessica 教的課。

### 寫法 1：雙重 NOT EXISTS

翻譯成白話：「**不存在**任何一門 Jessica 的課，是這個學生**沒有**修的」。

```sql
SELECT s.Sid, s.Sname
FROM Students s
WHERE NOT EXISTS (                       -- 不存在…
    SELECT * FROM Courses c
    WHERE c.Tname = 'Jessica'            -- …一門 Jessica 的課
      AND NOT EXISTS (                   -- …是他沒修的
          SELECT * FROM Takes t
          WHERE t.Sid = s.Sid AND t.Cno = c.Cno
      )
);
```

兩層子查詢都是**相關子查詢**：最內層同時用到外層的 `s.Sid` 和中間層的 `c.Cno`。

### 寫法 2：GROUP BY + HAVING COUNT

翻譯成白話：「這個學生修過的 Jessica 課程**門數**，等於 Jessica 開的課的**總門數**」。

```sql
SELECT s.Sid, s.Sname
FROM Students s
JOIN Takes t   ON t.Sid = s.Sid
JOIN Courses c ON c.Cno = t.Cno
WHERE c.Tname = 'Jessica'                      -- ① 只算 Jessica 的課
GROUP BY s.Sid, s.Sname                        -- ② 每個學生一組
HAVING COUNT(DISTINCT t.Cno) =                 -- ③ 他修的門數
       (SELECT COUNT(*) FROM Courses WHERE Tname = 'Jessica');   -- ＝ 總門數
```

### ⚠️ 寫法 2 的三個陷阱

| 陷阱 | 錯誤寫法 | 後果 |
|---|---|---|
| **忘了 ① 篩選** | 沒有 `WHERE c.Tname = 'Jessica'` | 會把其他老師的課也算進去，修很多別的課的人也會被選出來 |
| **忘了 DISTINCT** | `COUNT(t.Cno)` | 如果同一門課可能出現多次（例如重修、沒有主鍵限制），門數會算多 |
| **除數是空集合** | Jessica 一門課都沒開 | 寫法 1 回傳**所有學生**（「沒有任何一門課是他沒修的」成立）；寫法 2 回傳**空的**（沒有列通過 ①）。考試很少考，但面試或申論可能問 |

### 兩種寫法比較

| | 雙重 NOT EXISTS | GROUP BY + HAVING COUNT |
|---|---|---|
| 想法 | 「沒有一個是沒做的」（雙重否定） | 「做的數量 = 應做的數量」 |
| 好不好寫 | 比較抽象，要多練 | 比較直覺 |
| 除數是空集合 | 回傳全部 | 回傳空的 |
| 考題常見說法 | 「請使用 EXISTS」「相關子查詢」 | 「請使用 GROUP BY 分組運算」 |

💡 題目**指定**用哪種語法時，一定要照著寫，用另一種寫法會被扣分。
113 年國營「鐵粉」題和 115 年統計資訊類這題都是除法。
