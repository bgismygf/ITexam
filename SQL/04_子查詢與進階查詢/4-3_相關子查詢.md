# 4-3 相關子查詢 🎯

## 兩種子查詢

| | 非相關子查詢 | 相關子查詢（Correlated Subquery） |
|---|---|---|
| 子查詢是否用到外層的欄位 | 否 | **是** |
| 能不能單獨執行 | 可以 | **不行**（缺外層的值） |
| 執行次數 | **一次** | 外層**每一列都執行一次**（邏輯上） |

```sql
-- 非相關：子查詢自己就能跑
SELECT * FROM questions
WHERE score > (SELECT AVG(score) FROM questions);

-- 相關：子查詢用到外層的 q.exam_id
SELECT * FROM questions q
WHERE score > (SELECT AVG(score) FROM questions WHERE exam_id = q.exam_id);
```

## 範例：配分高於「該份考試」平均的題目

上面第二個 SQL 的意思是：對每一題，算出**它所屬那份考試**的平均配分，再比較。

執行過程（邏輯上）：
```
外層第 1 列：q.exam_id = 1 → 子查詢算出 exam 1 的平均 = 2.0 → 1.5 > 2.0？否
外層第 4 列：q.exam_id = 1 → 子查詢算出 exam 1 的平均 = 2.0 → 2.5 > 2.0？是 ✓
外層第 7 列：q.exam_id = 2 → 子查詢算出 exam 2 的平均 = 2.0 → 2 > 2.0？否
...
```

## 經典用法：每組中的最大值那一列

「每份考試中，配分最高的題目」：
```sql
SELECT q.exam_id, q.question_id, q.score
FROM questions q
WHERE q.score = (SELECT MAX(score) FROM questions WHERE exam_id = q.exam_id);
```

「每題最近一次的作答紀錄」：
```sql
SELECT * FROM practice_log p
WHERE p.answered_at = (SELECT MAX(answered_at) FROM practice_log
                       WHERE question_id = p.question_id);
```

這類「每組取第一名 / 最新一筆」的需求在工作上**非常常見**。
4-6 課的視窗函數會提供另一種（通常更好的）寫法。

## EXISTS 幾乎都是相關子查詢

上一課的 EXISTS 就是相關子查詢：
```sql
WHERE EXISTS (SELECT 1 FROM practice_log p WHERE p.question_id = q.question_id)
--                                                              ↑ 外層的欄位
```

## 💼 效能注意

- 相關子查詢「邏輯上」每列執行一次，資料量大時可能很慢
- 現代資料庫的最佳化器常常會自動改寫成 JOIN，但不一定每次都成功
- 遇到慢的相關子查詢，可以試著改寫成 **JOIN + GROUP BY** 或**視窗函數**

## 🎯 進階考題：用 NOT EXISTS 表達「全部」（除法）

「找出**每個**章節都有被作答過的…」這類「全部都要」的問題，在 SQL 中通常用
**雙重 NOT EXISTS** 表達：「不存在任何一個章節，是他沒做過的」。
這對應關聯代數的**除法 ÷**，第 6-8 課會詳細說明。
