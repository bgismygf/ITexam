# 4-7 常用函數：字串、日期、型態轉換 💼

函數是各家資料庫**差異最大**的地方。本課以 SQLite 示範，並列出其他資料庫的對照，
工作時遇到不同的資料庫，查對照表就好，不用死背。

## 字串函數

| 功能 | SQLite | MySQL | SQL Server |
|---|---|---|---|
| 長度 | `length(s)` | `CHAR_LENGTH(s)` | `LEN(s)` |
| 取子字串 | `substr(s, 起點, 長度)` | `SUBSTRING(s, 起點, 長度)` | `SUBSTRING(s, 起點, 長度)` |
| 轉大寫 / 小寫 | `upper(s)` / `lower(s)` | `UPPER` / `LOWER` | `UPPER` / `LOWER` |
| 去頭尾空白 | `trim(s)` | `TRIM(s)` | `TRIM(s)`（2017+） |
| 取代 | `replace(s, 舊, 新)` | `REPLACE` | `REPLACE` |
| 找位置 | `instr(s, 子字串)` | `INSTR` / `LOCATE` | `CHARINDEX(子字串, s)` |
| 串接 | `a \|\| b` | `CONCAT(a, b)` | `a + b` / `CONCAT(a, b)` |

⚠️ SQL 的字串位置**從 1 開始**，不是 0。

⚠️ 中文字的長度：SQLite 的 `length()` 算「字元數」（'資料庫' = 3）。
MySQL 的 `LENGTH()` 算「位元組數」（UTF-8 下 '資料庫' = 9），要用 `CHAR_LENGTH()` 才是字元數。

## 數值函數

| 功能 | 寫法 | 範例 |
|---|---|---|
| 四捨五入 | `ROUND(x, 小數位數)` | `ROUND(2.567, 1)` → 2.6 |
| 絕對值 | `ABS(x)` | `ABS(-3)` → 3 |
| 無條件進位 / 捨去 | `CEILING(x)` / `FLOOR(x)` | SQLite 3.35+ 支援 `ceil()` / `floor()` |
| 取餘數 | `x % y` 或 `MOD(x, y)` | `7 % 3` → 1 |

## 日期時間函數

SQLite 沒有專門的日期型態，通常用文字 `'YYYY-MM-DD HH:MM:SS'` 存放。

| 功能 | SQLite | MySQL | SQL Server |
|---|---|---|---|
| 現在時間 | `datetime('now', 'localtime')` | `NOW()` | `GETDATE()` |
| 今天日期 | `date('now', 'localtime')` | `CURDATE()` | `CAST(GETDATE() AS DATE)` |
| 取年 / 月 | `strftime('%Y', d)` / `strftime('%m', d)` | `YEAR(d)` / `MONTH(d)` | `YEAR(d)` / `MONTH(d)` |
| 加減日期 | `date(d, '+7 days')` | `DATE_ADD(d, INTERVAL 7 DAY)` | `DATEADD(day, 7, d)` |
| 兩日期相差天數 | `julianday(a) - julianday(b)` | `DATEDIFF(a, b)` | `DATEDIFF(day, b, a)` |
| 格式化 | `strftime('%Y/%m/%d', d)` | `DATE_FORMAT(d, '%Y/%m/%d')` | `FORMAT(d, 'yyyy/MM/dd')` |

💡 **民國年**：`年度 + 1911 = 西元年`。

💼 **工作提醒**：
- 日期一律用 **`YYYY-MM-DD`** 格式存放，排序和比較才會正確（'2026-11-03' > '2026-11-01'）
- 用 `'2026/1/3'` 這種格式存成文字，排序會出錯（'2026/1/3' > '2026/10/1'）
- 範圍查詢用「`>= 起日 AND < 隔天`」（1-3 課練習 6）

## 型態轉換

```sql
CAST(運算式 AS 型態)
```

| 範例 | 結果 |
|---|---|
| `CAST('123' AS INTEGER)` | 123（文字轉數字） |
| `CAST(7 AS REAL) / 2` | 3.5（避免整數除法） |
| `CAST(113 AS TEXT)` | '113'（數字轉文字） |

`CAST` 是標準 SQL，各家都支援。SQL Server 另外有 `CONVERT()`。

💼 **常見情境**：資料從 Excel 或 CSV 匯入時，數字常被存成文字，排序變成
'10' < '2'（文字比較），需要 CAST 成數字才會正確。

## 小測驗

1. `SUBSTR('資料庫系統', 3, 2)` 的結果為？
   (A) 料庫 (B) 庫系 (C) 資料 (D) 系統

<details>
<summary>看答案</summary>

**(B)**。從第 3 個字元開始，取 2 個字元：庫、系。
</details>
