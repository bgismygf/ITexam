# 0-2 DBMS 與常見產品 🎯💼

> 本課只有觀念，沒有練習檔。

## DBMS 是什麼

**DBMS（Database Management System，資料庫管理系統）** 是用來建立、管理、存取資料庫的軟體。

用比喻來說：
- **資料庫** 像是一間倉庫裡的貨物
- **DBMS** 像是倉庫管理員：負責上架、找貨、控制誰能進出、確保帳目正確
- **SQL** 是你跟管理員溝通的語言

## 常見的關聯式 DBMS

| 產品 | 公司 / 來源 | 費用 | 常見用途 |
|---|---|---|---|
| **SQLite** | 開源 | 免費 | 手機 App、小工具、學習用。整個資料庫就是**一個檔案**，不用架伺服器 |
| **MySQL** | Oracle（開源版免費） | 免費 / 商業版 | 網站最常見，例如 WordPress |
| **MariaDB** | 開源（MySQL 分支） | 免費 | 跟 MySQL 幾乎相容 |
| **PostgreSQL** | 開源 | 免費 | 功能完整，新創和科技公司愛用 |
| **SQL Server** | Microsoft | 商業（有免費版） | 企業、政府機關、Windows 環境很常見 |
| **Oracle Database** | Oracle | 商業（昂貴） | 大型企業、銀行、電信 |

💼 **工作提醒**：台灣的公家單位和國營事業常見 **SQL Server** 和 **Oracle**。

## 為什麼本教材用 SQLite 練習

- 不用安裝伺服器，打開檔案就能用
- 基本 SQL 語法跟其他產品幾乎一樣
- 學會之後換成 MySQL、SQL Server，大概九成語法可以直接沿用

**不同產品的語法差異範例**（先有印象就好）：

| 想做的事 | SQLite / MySQL / PostgreSQL | SQL Server | Oracle |
|---|---|---|---|
| 只取前 5 筆 | `LIMIT 5` | `TOP 5` | `FETCH FIRST 5 ROWS ONLY` |
| 取目前時間 | `datetime('now')`（SQLite）/ `NOW()` | `GETDATE()` | `SYSDATE` |

本教材遇到產品差異時，會特別標註。

## 🎯 資料模型的演進 📌（113 年計算機原理考過）

**資料模型**是「資料要用什麼結構來組織」。資料庫依照資料模型，大致分成四代：

| 資料模型 | 結構 | 比喻 | 代表產品 | 特色 |
|---|---|---|---|---|
| **階層式**（Hierarchical） | **樹狀**：一個父節點可以有多個子節點，但每個子節點**只能有一個父節點** | 公司組織圖 | IBM IMS | 只能表示 **1:N**；查詢要從根往下走 |
| **網狀式**（Network） | **圖狀**：一個子節點可以有**多個父節點** | 捷運路線圖 | IDMS（CODASYL 標準） | 可以表示 **M:N**，但指標關係複雜，程式難寫 |
| **關聯式**（Relational） | **二維表格**，表之間用**鍵值**關聯 | Excel 工作表 | Oracle、SQL Server、MySQL、PostgreSQL、Access | 用 SQL 查詢，**不用管資料實際怎麼存**；目前最主流 |
| **物件導向式**（Object-Oriented） | 把資料和操作包成**物件**，支援繼承、封裝 | 程式裡的 class | db4o、ObjectStore | 適合複雜資料（多媒體、CAD），但缺乏統一標準 |

```
年代     1960s          1970s          1980s～現在       1990s
        階層式  ──▶   網狀式   ──▶    關聯式      ◀──  物件導向式
       （樹）        （圖）          （表格）          （物件）
                                       │
                                  物件關聯式（Object-Relational）
                                  例：PostgreSQL、Oracle 加入物件功能
```

### 考試常見的判斷

| 敘述 | 對應的模型 |
|---|---|
| 子節點只能有一個父節點，只能表示 1:N | 階層式 |
| 用指標串連記錄，可表示 M:N | 網狀式 |
| 資料以二維表格呈現，用 SQL 存取 | 關聯式 |
| 支援繼承、封裝、方法 | 物件導向式 |
| 存 JSON 文件、不需要固定欄位 | **不是關聯式**，是 NoSQL（例如 MongoDB） |

⚠️ **常見陷阱**：**dBase**、**Microsoft Access** 雖然是比較舊或比較小的產品，但都**屬於關聯式資料庫**。
MongoDB 才是「非關聯式」（NoSQL）。

## 🎯 資料、資訊、詮釋資料（Metadata）

| 名詞 | 意思 | 例子 |
|---|---|---|
| **資料**（Data） | 原始的事實、數字，還沒經過處理 | 「A123、85」 |
| **資訊**（Information） | 資料經過**處理、整理**後，對決策**有意義** | 「本班平均 78 分，A123 高於平均」 |
| **詮釋資料**（Metadata） | **描述資料的資料** | 「成績欄位是整數，範圍 0～100，不可空白」 |

## 🎯 資料字典（Data Dictionary）

**資料字典**是 DBMS 用來存放**詮釋資料**的地方，又稱**系統目錄（System Catalog）**。

存放的內容：
- 有哪些**資料表、欄位**，各欄位的**資料型態**、長度
- **限制條件**：主鍵、外來鍵、UNIQUE、CHECK、NOT NULL
- **索引**、**View**、預存程序、Trigger 的定義
- **使用者**和**權限**
- 統計資訊（每張表有幾筆、欄位值的分布），給**查詢最佳化器**決定執行計畫用（8-4 課）

| 種類 | 意思 |
|---|---|
| **主動式**（Active）資料字典 | 由 DBMS **自動維護**，綱要一改就自動更新（現在的 DBMS 都是這種） |
| **被動式**（Passive）資料字典 | 要**人工**更新，容易和實際綱要不一致 |

各 DBMS 查資料字典的方法：

```sql
SELECT * FROM sqlite_master;                    -- SQLite：所有表、索引、View 的定義
SELECT * FROM information_schema.columns;       -- MySQL、SQL Server、PostgreSQL（SQL 標準）
SELECT * FROM user_tables;                      -- Oracle
```

💼 工作上接手陌生的資料庫時，先查資料字典就能知道有哪些表和欄位。

## 🎯 考試重點

- **DBMS 的功能**：資料定義、資料操作、安全控制、完整性控制、並行控制、備份與復原
- **三層架構（ANSI/SPARC）**（常考）：
  - **外部層（External / View Level）**：每個使用者看到的部分
  - **概念層（Conceptual / Logical Level）**：整個資料庫有哪些表、表之間的關係
  - **內部層（Internal / Physical Level）**：資料實際怎麼存放在硬碟上
- **資料獨立性**：
  - **邏輯資料獨立性**：概念層改變時，外部層（使用者的程式）不必改
  - **實體資料獨立性**：內部層改變時，概念層不必改

```
 使用者A   使用者B   使用者C
    \        |        /
     [   外部層 External  ]
              |        ← 邏輯資料獨立性
     [ 概念層 Conceptual ]
              |        ← 實體資料獨立性
     [  內部層 Internal   ]
              |
           (硬碟)
```

## 小測驗

1. 資料在硬碟上的儲存結構改變時，不需要修改概念層的設計，這稱為？
   (A) 邏輯資料獨立性 (B) 實體資料獨立性 (C) 資料完整性 (D) 資料一致性

2. 下列哪一個資料庫，整個資料庫就是一個檔案，不需要架設伺服器？
   (A) Oracle (B) SQL Server (C) SQLite (D) PostgreSQL

3. （113 年考題）下列何者**不屬於**關聯式資料庫？
   (A) Microsoft Access (B) dBase (C) PostgreSQL (D) MongoDB

4. 下列哪一種資料模型，每個子節點只能有一個父節點，因此只能直接表示 1:N 的關係？
   (A) 階層式 (B) 網狀式 (C) 關聯式 (D) 物件導向式

5. 下列哪一種資料模型支援繼承與封裝？
   (A) 階層式 (B) 網狀式 (C) 關聯式 (D) 物件導向式

6. DBMS 存放資料表定義、欄位型態、限制條件、使用者權限等詮釋資料的地方稱為？
   (A) 交易日誌 (B) 資料字典 (C) 資料倉儲 (D) 索引

2. **(C)** SQLite

5. **(D)** 物件導向式
6. **(B)** 資料字典（系統目錄）
