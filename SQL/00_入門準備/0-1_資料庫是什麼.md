# 0-1 資料庫是什麼？跟 Excel 有什麼不同

> 本課只有觀念，沒有練習檔。

## 一句話說明

**資料庫（Database）** 是一個「有組織地存放資料，並且讓很多人、很多程式能安全又快速地存取」的地方。

## 先從 Excel 想起

你可能用過 Excel 整理考古題：

| 年度 | 科目 | 題號 | 題目 | 答案 |
|---|---|---|---|---|
| 112 | 網路概論 | 1 | OSI 七層中負責路由的是？ | B |
| 112 | 網路概論 | 2 | HTTP 預設連接埠？ | C |

資料少的時候，Excel 很好用。但資料一多、使用的人一多，就會遇到問題：

| 問題 | Excel | 資料庫 |
|---|---|---|
| 資料量 | 約 100 萬列就到上限，而且很慢 | 上億筆也能處理 |
| 多人同時修改 | 容易互相覆蓋、檔案衝突 | 有「交易」機制保護（第 7 單元） |
| 資料正確性 | 什麼都能打，「B」打成「8」也不會警告 | 可以設規則，例如答案只能是 A～D（第 5 單元） |
| 重複資料 | 同一個科目名稱可能打了 100 次，改名要改 100 次 | 拆表存放，只要改一次（第 6 單元） |
| 查詢 | 靠篩選、樞紐分析，複雜條件很難做 | 用 SQL 一句話完成 |
| 權限 | 打開檔案就能看全部 | 可以控制誰能看、誰能改（第 9 單元） |

## 幾個重要名詞

- **資料庫（Database, DB）**：存放資料的地方本身
- **資料庫管理系統（DBMS）**：管理資料庫的軟體，例如 MySQL、SQL Server（下一課介紹）
- **SQL**（Structured Query Language，結構化查詢語言）：用來跟資料庫「溝通」的語言，
  讀音可以念 "S-Q-L" 或 "sequel"
- **關聯式資料庫（Relational Database）**：把資料存成一張一張「表格」，表格之間可以互相關聯。
  目前最主流，也是考試和本教材的重點

## 資料庫在工作中的樣子

你每天用的服務背後幾乎都有資料庫：
- 網路銀行：帳戶、交易紀錄
- 電商：商品、訂單、會員
- 公司內部系統：員工、薪資、請假
- 台電、中油：用戶、電表、帳單、設備維修紀錄

工程師寫的程式（網頁、App）負責畫面和流程，**資料都存在資料庫裡**，程式透過 SQL 去讀取和寫入。

```
使用者 → 網頁 / App → 程式 → (SQL) → 資料庫
```

## 🎯 考試重點

- 資料庫系統相較於「檔案系統」的優點（常考）：
  - 減少**資料重複（redundancy）**
  - 避免**資料不一致（inconsistency）**
  - 資料可以**共享**
  - 可以設定**安全性**與**完整性限制**
  - 提供**並行控制**與**故障復原**
  - **資料獨立性**：資料的存放方式改變時，不需要修改應用程式

## 小測驗

1. 下列何者「不是」資料庫系統相較於檔案系統的優點？
   (A) 減少資料重複 (B) 可做並行控制 (C) 資料一定不會遺失 (D) 可設定存取權限

<details>
<summary>看答案</summary>

**(C)**。資料庫有備份與復原機制，可以「降低」遺失的風險，但不能保證資料一定不會遺失。
</details>
