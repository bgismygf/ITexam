# 0-3 安裝環境，跑第一個查詢

## 要安裝什麼

**DB Browser for SQLite**：免費、有圖形介面，最適合新手用來打開 SQLite 資料庫、執行 SQL。

## 步驟 1：下載安裝

1. 到官網 <https://sqlitebrowser.org/dl/>
2. 選 **Windows** 版本，下載 `Standard installer for 64-bit Windows`（.msi 檔）
3. 執行安裝檔，一路按 Next 就可以
4. 安裝完成後，從開始選單打開 **DB Browser (SQLite)**

> 想把介面改成中文：選單 `Edit → Preferences → General → Language`，選「Chinese (Taiwan)」，重新開啟程式。
> 本教材以英文介面名稱為主，括號附中文。

## 步驟 2：打開練習資料庫

1. 按上方的 **Open Database**（開啟資料庫）
2. 選擇 `桌面\資訊\SQL\data\exam.db`
3. 在 **Database Structure**（資料庫結構）分頁，會看到 6 張資料表：

| 資料表 | 內容 |
|---|---|
| `exams` | 考試（每份試卷一筆） |
| `questions` | 題目 |
| `options` | 選項 A～D |
| `topics` | 章節主題 |
| `question_topics` | 題目屬於哪些章節 |
| `practice_log` | 作答紀錄 |

4. 切到 **Browse Data**（瀏覽資料）分頁，可以像 Excel 一樣看到表格內容

## 步驟 3：執行第一個 SQL

1. 切到 **Execute SQL**（執行 SQL）分頁
2. 按 **Open SQL file**（開啟 SQL 檔案）的資料夾圖示，選本課的 `0-3_安裝環境.sql`
3. 執行方式：

| 快捷鍵 | 效果 |
|---|---|
| `Ctrl + Enter` 或 `F5` | 執行全部（如果有反白選取，就只執行選取的部分） |
| `Shift + F5` | 只執行游標所在的那一句 |

4. 結果會顯示在下方的表格

💡 **建議**：一次只執行一句（用 `Shift + F5`，或反白後按 `Ctrl + Enter`），比較容易看懂每句的結果。

## 重要：關於「寫入變更」

- 只是**查詢**（`SELECT`）不會改到資料，可以放心執行
- 之後學到**修改資料**（`INSERT`、`UPDATE`、`DELETE`）時，DB Browser 不會馬上存檔，
  要按 **Write Changes**（寫入變更，`Ctrl + S`）才會真正寫入；
  按 **Revert Changes**（還原變更）可以放棄修改

## 資料庫改壞了怎麼辦（還原方法）

1. 關閉目前的資料庫（**Close Database**）
2. 把 `data\exam.db` 刪掉
3. 按 **New Database**（新建資料庫），存成 `data\exam.db`（如果跳出建立資料表的視窗，按取消）
4. 到 **Execute SQL**，開啟 `data\建立題庫.sql`，按 `Ctrl + Enter` 全部執行
5. 按 **Write Changes**（`Ctrl + S`）存檔

## SQL 書寫的基本規則

- 每一句 SQL 用**分號 `;`** 結尾
- **關鍵字不分大小寫**：`SELECT` 和 `select` 一樣。習慣上關鍵字用大寫，比較好讀
- **文字要用單引號** `'文字'`，數字不用引號
- **註解**：
  - `-- 這是單行註解`
  - `/* 這是 多行註解 */`
- 可以任意換行和縮排，資料庫會忽略多餘的空白
