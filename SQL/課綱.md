# SQL 與資料庫課綱

## 課程目標

- **考試**：國營事業聯合招考（經濟部所屬事業機構）「資訊類」的資料庫部分
  - 主戰場：**專業科目 B「資訊管理」**的「資料庫管理」，**非測驗題，要手寫 SQL 和計算過程**
  - 次要：專業科目 A「計算機原理」的選擇題，每年約 1～4 題
- **工作**：能在實務上查資料、設計資料表、看懂和改寫別人的 SQL
- **對象**：資料庫新手，從零開始，由淺入深

## 考試概況

依 109 年簡章的官方命題大綱：

| 科目 | 題型 | 資料庫的分量 |
|---|---|---|
| 專業科目 A：計算機原理＋網路概論 | 50 題選擇題 | 大綱沒有列資料庫，但每年仍有 1～4 題 |
| 專業科目 B：資訊管理＋程式設計 | 非測驗題（申論、手寫程式），120 分鐘，不能用計算機 | 「資訊管理」大綱第三項就是「資料庫管理」，每年約 15～40 分（滿分 100） |

歷屆真題整理和出題比重，請看 [10-5 考古題實戰](10_實戰與延伸/10-5_考古題實戰.md)。

**考試前最重要的三件事**
1. **能在紙上寫出正確的 SQL**：110、112、113 年連續考，每年約 15 分
2. **NoSQL 與大數據**：107 年考了 40 分，選擇題也常出現
3. **正規化與索引計算**：109 年考正規化，113 年考 B+ Tree 硬碟頁存取計算

## 每一課的格式

每課有兩個檔案（純觀念的課只有 `.md`）：

| 檔案 | 內容 |
|---|---|
| `.md` 講義 | 1. 觀念說明（盡量白話）<br>2. 語法與圖解<br>3. 🎯 考試重點<br>4. 💼 工作小技巧<br>5. 小測驗（附答案） |
| `.sql` 練習 | 1. 可以直接執行的範例<br>2. 練習題<br>3. 解答（放在檔案最下方） |

## 學習方式

1. 讀 `.md` 講義
2. 在 DB Browser for SQLite 執行 `.sql` 的範例
3. 自己寫練習題，再對解答
4. 到 [README.md](README.md) 的進度表打勾

> ✍️ **考試要手寫**：科目 B 不能用電腦，SQL 要寫在答案卷上。寫練習題時，建議**先在紙上寫完，再到電腦執行驗證**，習慣不靠自動補全和錯誤訊息。

### 考試時間不夠時的優先順序

依歷屆真題的出題比重排列：

1. **手寫 SQL**：第 1～4 單元，加上 5-3（看懂 DDL）
2. **正規化**：6-1、6-6、6-7
3. **NoSQL 與大數據**：10-4
4. **索引計算**：8-1、8-2
5. **資料清理與程式寫入資料庫**：10-1、10-2
6. **零星考點**：0-2（資料庫類型）、9-1（View）、9-5（SQL Injection）
7. **最後再讀**：第 7 單元、6-2、6-3、6-5、6-8 的符號推導、6-9 EER

> 只考國營聯招時照上面的順序；如果也要考高普考、地方特考等考選部的考試，第 7 單元、6-5、6-9 要提前，這些在考選部的「資料庫應用」幾乎每年都考。
