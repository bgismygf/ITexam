# 2-1 彙總函數 🎯💼

## 觀念

前一單元查出來的是「一筆一筆的資料」。**彙總函數（Aggregate Function）** 則是把**很多筆資料算成一個值**，
例如總共幾題、平均幾分。

## 五個基本彙總函數

| 函數 | 作用 | 範例 |
|---|---|---|
| `COUNT()` | 計算筆數 | 共有幾題 |
| `SUM()` | 加總 | 總分是多少 |
| `AVG()` | 平均 | 平均配分 |
| `MAX()` | 最大值 | 最高配分 |
| `MIN()` | 最小值 | 最早的年度 |

```sql
SELECT COUNT(*), SUM(score), AVG(score), MAX(score), MIN(score)
FROM questions;
```

## 🎯 COUNT 的三種寫法（必考）

| 寫法 | 計算什麼 | NULL 怎麼處理 |
|---|---|---|
| `COUNT(*)` | **列數** | 算進去 |
| `COUNT(欄位)` | 該欄位**不是 NULL** 的筆數 | **不算** |
| `COUNT(DISTINCT 欄位)` | 該欄位**不重複、不是 NULL** 的值有幾種 | **不算** |

以題庫為例（30 題，第 29 題 answer 是 NULL）：
```sql
COUNT(*)               -- 30
COUNT(answer)          -- 29（少了 NULL 那題）
COUNT(DISTINCT answer) -- 4（A、B、C、D）
```

## 🎯 彙總函數會忽略 NULL

除了 `COUNT(*)`，**所有彙總函數都會忽略 NULL**。

這會影響 AVG 的結果：假設三個人的分數是 80、NULL、100
- `AVG(分數)` = (80 + 100) / **2** = 90（NULL 不算在分母）
- 如果把 NULL 當成 0：(80 + 0 + 100) / **3** = 60

如果你要的是後者，要寫 `AVG(COALESCE(分數, 0))`。

另外：
- 資料全部是 NULL（或沒有資料）時，`SUM`、`AVG`、`MAX`、`MIN` 回傳 **NULL**
- `COUNT` 則回傳 **0**

## 搭配 WHERE

`WHERE` 先篩選，再彙總：
```sql
SELECT COUNT(*) FROM questions WHERE exam_id = 1;   -- 第 1 份考試有幾題
```

## MAX / MIN 也能用在文字和日期

```sql
SELECT MAX(answered_at) FROM practice_log;   -- 最近一次作答時間
SELECT MIN(name) FROM topics;                -- 依字元排序最小的名稱
```

## ⚠️ 常見錯誤：彙總函數和一般欄位混用

```sql
SELECT question_id, MAX(score) FROM questions;
```
想查「配分最高的題目是哪一題」，但這樣寫是**錯的**：
- 標準 SQL、SQL Server、PostgreSQL、Oracle：直接報錯
- SQLite、舊版 MySQL：不報錯，但 question_id 可能是隨便一筆

正確作法要用子查詢（第 4 單元）或排序：
```sql
SELECT question_id, score FROM questions ORDER BY score DESC LIMIT 1;
```

規則：**SELECT 裡有彙總函數時，其他欄位必須出現在 GROUP BY 裡**（下一課）。

## 💼 工作小技巧

- `COUNT(*)` 是查資料量最常用的寫法，例如確認匯入的資料筆數對不對
- 金額加總要注意欄位型態，用 `DECIMAL` 而不是 `REAL / FLOAT`，避免小數誤差
- 計算「比例」時，要注意整數除法：`SUM(is_correct) * 1.0 / COUNT(*)`

## 小測驗

1. 資料表 T 的欄位 x 有 5 筆資料：10、20、NULL、20、NULL。下列結果何者錯誤？
   (A) `COUNT(*)` = 5 (B) `COUNT(x)` = 3 (C) `COUNT(DISTINCT x)` = 2 (D) `AVG(x)` = 10

2. 承上題，`SUM(x)` 的結果為？
   (A) 50 (B) NULL (C) 0 (D) 語法錯誤

<details>
<summary>看答案</summary>

1. **(D)**。AVG 忽略 NULL：(10 + 20 + 20) / 3 ≈ 16.67
2. **(A)**。SUM 忽略 NULL：10 + 20 + 20 = 50
</details>
