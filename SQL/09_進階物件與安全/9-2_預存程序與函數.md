# 9-2 Stored Procedure 預存程序、Function 💼

> ⚠️ **SQLite 不支援預存程序和自訂函數**，本課只有講義。
> 範例以 **SQL Server（T-SQL）** 和 **MySQL** 為主，等你接觸到這兩種資料庫時可以實際練習。
> 免費的練習環境：SQL Server Express / Developer Edition、MySQL Community Server，
> 或線上的 [db-fiddle](https://www.db-fiddle.com/)、[sqlfiddle](http://sqlfiddle.com/)。

## 觀念

**預存程序（Stored Procedure）** 是「**存在資料庫裡的一段程式**」，
可以包含多句 SQL、變數、條件判斷、迴圈，用一個名稱呼叫執行。

💡 **類比**：程式語言裡的「函式」，只是它存放在資料庫中、在資料庫裡執行。

## 範例：記錄一次作答（自動判斷對錯）

### SQL Server（T-SQL）

```sql
CREATE PROCEDURE sp_answer_question
    @question_id INT,
    @chosen      CHAR(1)
AS
BEGIN
    DECLARE @answer CHAR(1);
    DECLARE @is_correct BIT;

    SELECT @answer = answer FROM questions WHERE question_id = @question_id;

    IF @answer IS NULL
    BEGIN
        RAISERROR('題目不存在或尚未設定答案', 16, 1);
        RETURN;
    END

    SET @is_correct = CASE WHEN @chosen = @answer THEN 1 ELSE 0 END;

    INSERT INTO practice_log (question_id, answered_at, chosen, is_correct)
    VALUES (@question_id, GETDATE(), @chosen, @is_correct);

    SELECT @is_correct AS is_correct, @answer AS correct_answer;
END;

-- 呼叫
EXEC sp_answer_question @question_id = 8, @chosen = 'B';
```

### MySQL

```sql
DELIMITER //
CREATE PROCEDURE sp_answer_question(IN p_question_id INT, IN p_chosen CHAR(1))
BEGIN
    DECLARE v_answer CHAR(1);

    SELECT answer INTO v_answer FROM questions WHERE question_id = p_question_id;

    INSERT INTO practice_log (question_id, answered_at, chosen, is_correct)
    VALUES (p_question_id, NOW(), p_chosen, p_chosen = v_answer);

    SELECT p_chosen = v_answer AS is_correct, v_answer AS correct_answer;
END //
DELIMITER ;

-- 呼叫
CALL sp_answer_question(8, 'B');
```

> MySQL 的 `DELIMITER //` 是暫時把結束符號從 `;` 改成 `//`，
> 否則程序內部的 `;` 會被當成整個 CREATE 的結束。

## 預存程序 vs 函數（Function）

| | 預存程序 Procedure | 函數 Function |
|---|---|---|
| 回傳值 | 可以沒有，或回傳多個結果集 | **必須**回傳一個值（或一張表） |
| 呼叫方式 | `EXEC` / `CALL` | 在 SQL 中使用，例如 `SELECT dbo.fn_xxx(欄位)` |
| 可以修改資料嗎 | ✅ 可以 | ❌ 通常不行（SQL Server 的函數不能修改資料） |
| 用途 | 執行一連串的業務邏輯 | 計算、轉換 |

### 函數範例（SQL Server）

```sql
CREATE FUNCTION dbo.fn_roc_to_ad (@roc_year INT)
RETURNS INT
AS
BEGIN
    RETURN @roc_year + 1911;
END;

SELECT year, dbo.fn_roc_to_ad(year) AS ad_year FROM exams;
```

## 💼 優點與缺點

| 優點 | 缺點 |
|---|---|
| **效能**：預先編譯，減少網路往返（多句 SQL 一次送過去） | **不容易版本控制、測試、除錯** |
| **安全性**：只授權使用者執行程序，不直接存取資料表 | 業務邏輯分散在程式和資料庫兩邊 |
| **防止 SQL Injection**：參數化的 | **綁定特定資料庫**，換資料庫要重寫 |
| 多個應用程式共用同一套邏輯 | 資料庫伺服器負擔變重 |

💼 **實務趨勢**：
- 傳統企業、銀行、政府系統（大量使用 SQL Server、Oracle）：**預存程序很常見**，
  進入國營事業工作很可能會遇到大量的預存程序（Oracle 的叫 PL/SQL）
- 新創、網路公司：傾向把邏輯放在應用程式，資料庫只負責存取資料

## 各資料庫的程序語言

| 資料庫 | 程序語言 |
|---|---|
| SQL Server | **T-SQL**（Transact-SQL） |
| Oracle | **PL/SQL** |
| PostgreSQL | **PL/pgSQL** |
| MySQL | SQL/PSM（無特別名稱） |
