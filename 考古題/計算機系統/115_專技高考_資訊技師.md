※注意：(一)禁止使用電子計算器。

(二)不必抄題，作答時請將試題題號及答案依照順序寫在試卷上，於本試題上作答者，不予計分。

(三)本科目除專門名詞或數理公式外，應使用本國文字作答。

**一、**請詳述下列計算機系統名詞的差異。（每小題 5分，共 20分）

(一) NPU（Neural Processing Unit）vs TPU（Tensor Processing Unit）

(二) Multi-Core Computer vs Cluster Computer

(三) Multi-processes OS vs Multi-threads OS

(四) DDR-DRAM vs HBM（High Bandwidth Memory）

**二、**請詳述作業系統的兩種 IPC（Inter-Process Communications）在下列四個問題上的差異性：這兩種 IPC 分別是共享記憶體（Shared-Memory）與訊息傳送（Message-Passing）。（每小題 5 分，共 20分）

(一)記憶體使用上的差異性。

(二)程式（Programming）撰寫時的差異性。

(三)程序（Process）通訊所需時間的差異性。

(四)在多核系統（Multi-Cores）運作的差異性。

**三、**請依序寫出被 CPU 執行以下七個作業系統相關軟體程式的排列順序（Precedence）。⑴Loader；⑵Linker；⑶Program in Main Memory；⑷Source Program；⑸Executable File；⑹Object File；⑺Compiler。（20分）

**四、**有一顆 5.0 GHz的 CPU，執行平均有 2,000 個指令（Instruction）的程式（Program），假設 CPU 完成一個指令需要 2 個 CPU cycles 做指令解碼（Instruction Decoding），3 個 CPU cycles 做指令執行（Instruction Execution），與 5個 CPU cycles做記憶體存取（Memory Access）。（每小題10 分，共 20 分）

(一)計算 MIPS（Million Instructions per Second）。

(二)計算 CPU throughput（Programs per Second）。

**五、**假設有一個計算機系統的存取架構：⑴TLB（Translation Lookaside Buffer）的HR（Hit Ratio）是70%；⑵Page Table的HR是80%；⑶TLB的

−9存取時間（Access Time）= 20 nsec(nsec = 10 sec)；⑷Page Table的存取時間= 100 nsec；⑸主記憶體（Main Memory）的存取時間= 100 nsec；⑹Disk 的存取時間是 800 nsec，請計算此一計算機系統整體的有效存取時間（Effective Access Time）。（20分）
