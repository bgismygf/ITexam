**一、**在一個一對一的二元關係（one-to-one binary relationship）中，若其中一個檔案為選擇性參與者（optional participant），而另一個檔案為強迫性參與者（mandatory participant），在邏輯資料庫設計（logical database design）中有二種方式來處理這一個二元關係，請分別說明這二種處理方式，並論述那一種處理方式較佳。（25分）

**二、**針對產品資料檔Product_T，用結構化查詢語言（structured query language, SQL）所撰寫之指令如下所示，其中 ProductFinish 表示產品的生產地，而 ProductStandardPrice表示產品的標準價格。請說明此指令所要完成的工作，並說明當資料庫管理系統（database management system, DBMS）接收到此指令後的執行步驟，以及清楚說明各步驟的執行內容和先後順序。（25分）SELECTProductFinish,AVG(ProductStandardPrice)FROMProduct_T

WHEREProductFinish IN(‘臺北’, ‘臺南’)GROUP BYProductFinish

```
HAVINGAVG(ProductStandardPrice) < 500 ORDER BYProductFinish;
```

**三、**在進行邏輯資料庫設計（logical database design）時，需要建立一個檔案的主鍵（primary key），此時會要求一個主鍵欄位的值不可以重複，請論述這個要求的必要性；一般會建議主鍵欄位的值要儘量不會被更動，並且主鍵欄位的長度要越短越好，請分別說明這二個建議的原因。（25 分）
