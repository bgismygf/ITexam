**五、**初始為空的最小堆積樹(Min-Heap)，給定以下6個整數的資料數列：45, 32, 28, 15, 8, 25。

**六、**某半導體代工廠希望分析每日產能是否能穩定達到生產目標。請撰寫一函式，計算每日產能達到或超過目標值的最長連續天數，並註明所使用的程式語言。（20分）函式介面如下：

```
int maxDays(int Production[], int N, int Target)
```

輸入參數：

1. Production：整數陣列，記錄連續N天的每日產能

2. N：整數，表示陣列Production的長度

3. Target：整數，表示每日目標產能回傳值：

回傳一個整數，表示Production中連續「產能大於或等於Target」的最大天數範例：

Production = [1200, 800, 1500, 1300, 900, 1100, 1400, 1600]

N = 8

Target = 1000

輸出：3說明：

產能大於或等於1000的連續區段為：

¬ [1200]：連續1天

¬ [1500, 1300]：連續2天

¬ [1100, 1400, 1600]：連續3天因此，最大連續天數為3
