**一、**供應商及其所銷售產品的關聯式資料庫(Relation Database)，包含下列 2 個資料表(table)，有底線為主鍵(Primary Key)：

供應商(Suppliers)資料表

```
供應商代號   供應商名稱   城市名稱
(SupplierID)   (SupplierName)   (City)
```

產品(Products)資料表

```
 產品代號   產品名稱   供應商代號   價格
(ProductID)   (ProductName)   (SupplierID)   (Price)
```

針對下列問題，請分別寫出SQL指令以進行查詢。（3題，共15分）

(一)列出供應商名稱及其所銷售產品名稱，其中供應商代號從小到大排序，產品代號從大

到小排序。（3分）

(二)使用 SQL 萬用字元(Wildcards)列出供應商名稱及城市名稱，其城市名稱第 2 個字母包

含a, e, i。（5分）

(三)使用SQL EXISTS語法列出產品價格> 100的供應商名稱。（7分）
