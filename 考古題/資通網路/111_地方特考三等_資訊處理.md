**一、**TCP 提供連接導向服務，請以主從架構模式說明 TCP 連線建立過程與TCP Header中的那些欄位用於 TCP連線建立過程。（20分）

**二、**目前網路大多以 HTTP Streaming 傳輸影音串流，DASH 為 HTTP Streaming 之一。請說明 DASH影音串流傳輸運作方式。（20 分）

**三、**無線網路傳輸不同於有線網路傳輸，請說明使用無線傳輸時，何種問題會造成無線傳輸通道損傷？（20分）

**四、**請說明 whois 協定用途與可查詢那些資訊。（20分）

**五、**請說明Zero-Day Attack發生時機，會帶來何種資安危機與該如何因應。（20分）
