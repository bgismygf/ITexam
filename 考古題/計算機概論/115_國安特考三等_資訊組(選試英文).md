**六、**寫出下列 Python語言程式的輸出，並詳細解釋程式的執行流程。（20 分）

```
def foo(arr):
    n = len(arr)
    if n <= 1:
        return
    for i in range(1, n):
        key = arr[i]
        j = i - 1
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
        print(arr)
arr = [35, 91, 25, 30, 6, 18, 8, 55]
foo(arr)
```
