```

※注意：(一)禁止使用電子計算器。

(二)不必抄題，作答時請將試題題號及答案依照順序寫在試卷上，於本試題上作答者，不予計分。

(三)本科目除專門名詞或數理公式外，應使用本國文字作答。

**一、**請比較線性搜尋（Linear Search）與二分搜尋（Binary Search），回答下列問題：

(一)兩種搜尋方法各自需要什麼條件才能正確執行？（6分）

(二)若資料共有 1,000 筆，則最多需要比較幾次才能完成搜尋工作？分別分析兩種方法的最壞情況時間複雜度。（6分）

(三)如果資料尚未排序，且只需要搜尋一次，先排序再使用 Binary Search是否合理？請說明理由。（8分）

**二、**定義正規二元樹（Full Binary Tree）為每個節點恰有 0 個或 2 個子節點的二元樹。令 I(T)表示內部節點數量，L(T)表示葉節點數量。請回答：

(一)寫出正規二元樹的遞迴定義。（6 分）

(二)證明任何非空（non-empty）正規二元樹均滿足L(T)=I(T)+1。（8分）

(三)若有 15個內部節點，計算其葉節點數量與總節點數量。（6分）

**三、**某超市蒐集了 500 筆交易紀錄，分析後得到以下結果：

• 所有商品的購物交易總筆數：500 筆

• 包含購買麵包交易筆數：200筆。

• 包含購買牛奶的交易筆數250筆。

• 包含同時購買麵包與牛奶的交易筆數：100 筆。請根據上述資料，回答下列問題（(一)(二)(三)小題請先寫出公式後再計算）：

（每小題 4分，共 20 分）

(一)計算關聯規則「購買麵包→購買牛奶」的支持度（Support）。

(二)計算關聯規則「購買麵包→購買牛奶」的信賴度（Confidence）。

(三)計算關聯規則「購買牛奶→購買麵包」的信賴度（Confidence）。

(四)提升度（Lift）可用來衡量兩項商品之間的關聯程度。請計算「購買麵包→購買牛奶」的提升度，並說明其數值代表的意義。提升度的計算公式：Lift(X->Y) = Confidence(X->Y)/Support(Y)

(五)根據上述計算結果，說明「購買麵包→購買牛奶」與「購買牛奶→購買麵包」這兩條規則的信賴度為何可能不同。

**四、**某校有以下三個資料表：（每小題 10 分，共20分）

```
資料表一：STUDENT   資料表二：COURSE   資料表三：ENROLLMENT
 StudentID Name Department Age CourseID CourseName Credits StudentID CourseID Grade
 S001   Amy CS   20   C01   Database   3   S001   C01   85
 S002   Bob EE   22   C02   Programming 3   S001   C02   90
 S003   Cindy CS   21   C03   Statistics   2   S002   C01   72
 S004   David ME   23   S003   C01   95
 S005   Eric CS   22   S003   C03   88
                                                            S004   C02   65
                                                            S005   C01   78
                                                            S005   C02   82

(一)請撰寫 SQL 查詢，列出 STUDENT 資料表中所有屬於 CS 系所的學生，並依照年齡由大到小排列。輸出欄位為 StudentID、Name、Age。

(二)請撰寫 SQL查詢，列出每位學生的姓名、課程名稱及成績。要求使用STUDENT、COURSE與 ENROLLMENT三個資料表，只列出確實有選課紀錄的學生，並依學生姓名及課程名稱排序。
