**一、**在 C++或 Java語言中，如何實作例外處理（exception handling）？請詳述並舉例說明。（20 分）

**二、**請使用 C++或 Java語言，設計一個method 來計算費式數列其中的一項。（20分）此 method 的設計需求如下：

• 名稱為 fi

• 僅有一個輸入參數 n。n為大於或等於零的整數。

• 回傳值為整數。其值的計算方式：

```
fi(0) = 0; fi(1) = 1; fi(n) = fi(n-1) + fi(n-2), n >= 2。
```

• 不可使用遞迴（recursion）。

**三、**下列 Objx.java程式，執行的輸出為何？需詳述執行過程。若將 static int x = 0；這行程式中的 static刪除，是否還可以執行？若可以執行，則輸出為何？若無法執行，請說明原因。（20分）

```
public class Objx
{
   static int x = 0;
   public int m1 (int n)
   {
      x++;
      if (n <= 0) return x;
      else return (m1(n - 2) + m1(n / 2));
   }
   public static void main (String args[])
   {
      Objx a1 = new Objx();
      Objx a2 = new Objx();
      System.out.println(a1.m1(3));
      System.out.println(a2.m1(4));
   }
}
```

**四、**物件導向程式設計，使用 C++或Java撰寫。（40分）請寫一個名為 Employee（職員）的類別（class），其中包含一個欄位basicSalary（int整數）代表基本薪水。此外，Employee類別包含兩個方法（methods)：

• 建構函式（constructor）：接受一個整數參數作為 basicSalary 的設定

值。

• 公共方法（public method）：getPay()回傳員工的 basicSalary。設計兩個名為 Manager（經理）和Programmer（程式設計師）的類別，這兩個類別都繼承 Employee類別。這兩個類別的描述如下：

• Manager

o 一位經理可以有多位程式設計師作為其團隊成員。經理除了基本

薪水外還有管理加給，就是每位團隊成員薪水的10%之總和。

o 公共方法 addMember來增加團隊成員。

o 呼叫 getPay()方法，它將回傳經理的總薪水。

• Programmer

o 一個欄位 years（int 整數）代表工作年資，其建構函式接受一個

整數參數作為 years 的設定值。

o 程式設計師的薪水計算方式為（基本薪水+ 2000 *年資）。

o 呼叫 getPay()方法，它將回傳程式設計師的薪水。最後寫一個 Main 類別來執行以下操作：

• 創建一個程式設計師 p1，基本年薪為 50000元，工作年資為 10年。

• 創建一個程式設計師 p2，基本年薪為 60000元，工作年資為 5年。

• 創建一個程式設計師 p3，基本年薪為 70000元，工作年資為 4年。

• 創建一個經理 m1，基本年薪為 100000 元，並將p1和 p2 加入 m1 的

團隊成員。

• 創建一個經理 m2，基本年薪為 120000 元，並將 p3 加入 m2 的團隊

成員。

• 列印出經理 m1 和經理 m2 的薪資。
