**一、**請以時間複雜度之漸近符號觀念回答下列問題。(一)、(二)題為二個程式片段分別以漸近符號Θ(Theta)與 n 表示其時間複雜度。（時間複雜度之漸近符號分 O、Ω、Θ三種，定義不同，(一)、(二)題請以Θ回答）。

(一)（5分）

```
sum=0;
for (i=0; i<n; i=i+2)
  for (j=0; j<i;j++)
     sum=sum+1;
```

(二)（5分）

```
sum=0; i=0;
while (i<n) {
  for (j=i; j<=n; j++)
    sum=sum+1;
  i=i+1;
};
```
