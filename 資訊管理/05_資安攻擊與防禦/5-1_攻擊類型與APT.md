# 5-1 攻擊類型與 APT 🎯💼

> 對應考古題：109（APT 攻擊的流程與資訊管理人員的因應對策）

## 觀念

第 4 單元講「怎麼保護」，這個單元講「**攻擊者會怎麼打**」。知道攻擊手法，才知道防護措施要放在哪裡。

## 🎯 惡意程式（Malware）

| 種類 | 特徵 | 怎麼散播 |
|---|---|---|
| **病毒**（Virus） | 依附在其他檔案或程式上，**需要使用者執行**才會發作 | 隨著被感染的檔案傳遞 |
| **蠕蟲**（Worm） | **不需要依附**，能**自行複製**、透過網路自動散播 | 利用系統漏洞，快速擴散 |
| **木馬**（Trojan Horse） | **偽裝成正常程式**，暗中執行惡意功能（例如開後門），本身通常不會自我複製 | 誘騙使用者下載安裝 |
| **勒索軟體**（Ransomware） | **加密**受害者的檔案，要求付贖金才給解密金鑰；近年常「**雙重勒索**」：先偷資料，再威脅公開 | 釣魚郵件、遠端桌面弱密碼、系統漏洞 |
| **間諜軟體**（Spyware） | 暗中蒐集使用者資料（鍵盤記錄、帳密） | 夾帶在免費軟體中 |
| **Rootkit** | 取得最高權限並**隱藏自己**，讓防毒軟體找不到 | 通常由其他惡意程式安裝 |
| **殭屍網路**（Botnet） | 大量被控制的電腦（殭屍），聽從**中繼站（C2）**的指令一起行動 | 用來發動 DDoS、寄垃圾郵件 |

💡 **病毒 vs 蠕蟲**：病毒要「搭便車」而且要有人執行；蠕蟲自己會跑、自己會傳。

## 🎯 常見網路攻擊

| 攻擊 | 手法 | 破壞的特性 | 防範 |
|---|---|---|---|
| **DoS／DDoS**（阻斷服務／分散式阻斷服務） | 用大量流量或請求塞爆目標，讓正常使用者無法使用；DDoS 是用殭屍網路從**大量來源**同時攻擊 | **可用性** | 流量清洗服務、CDN、限流、備援頻寬 |
| **中間人攻擊**（MITM） | 攻擊者介入雙方通訊之間，竊聽或竄改內容（例如假的公共 Wi-Fi） | 機密性、完整性 | 使用 HTTPS／TLS、VPN、驗證憑證 |
| **密碼攻擊** | **暴力破解**（試所有組合）、**字典攻擊**（試常見密碼）、**撞庫**（Credential Stuffing，拿其他網站外洩的帳密來試） | 機密性 | 多因子認證、登入失敗鎖定、不同網站用不同密碼 |
| **零時差攻擊**（Zero-day） | 利用**廠商還不知道或還沒修補**的漏洞 | 視漏洞而定 | 縱深防禦、異常行為偵測、虛擬修補（WAF） |
| **供應鏈攻擊** | 先入侵**軟體供應商或委外廠商**，再透過更新檔或維運管道進入真正的目標 | 視情況而定 | 廠商資安要求、驗證更新檔簽章、限制廠商存取權限 |

社交工程（釣魚、BEC）見 5-2 課，Web 攻擊（SQL Injection、XSS、CSRF）見 5-3 課。

## 🎯 進階持續性威脅（APT）

**APT（Advanced Persistent Threat）**：針對**特定組織**，經過長期規劃、手法複雜、**長期潛伏**的網路攻擊，通常有國家或大型組織在背後支持，目的多半是**竊取機密**或**破壞關鍵基礎設施**。

| 字母 | 意思 |
|---|---|
| **A**dvanced 進階 | 結合多種攻擊手法，常用零時差漏洞、客製化惡意程式 |
| **P**ersistent 持續 | **長期潛伏**，可能數月甚至數年才被發現；被清除後還會再回來 |
| **T**hreat 威脅 | 有明確目標和動機，背後有組織支持 |

APT 和一般攻擊的差別：

| | 一般攻擊 | APT |
|---|---|---|
| 目標 | 廣撒網，誰中誰倒楣 | **鎖定特定組織** |
| 時間 | 打了就走 | **長期潛伏** |
| 目的 | 勒索、炫技 | **竊取機密、破壞關鍵基礎設施** |
| 手法 | 現成工具 | 客製化工具、零時差漏洞、社交工程 |

國營事業（能源、水資源）是關鍵基礎設施，是 APT 的主要目標之一。

### 🎯 APT 攻擊流程

教科書常見的寫法有兩種，作答時擇一完整寫出即可。

**寫法一：六個階段（常見的中文教材寫法）**

```
① 情報蒐集 → ② 初始入侵 → ③ 建立據點 → ④ 權限提升與橫向移動 → ⑤ 資料竊取 → ⑥ 長期潛伏、清除痕跡
```

| 階段 | 攻擊者做什麼 | 例子 |
|---|---|---|
| ① **情報蒐集** | 調查目標組織的人員、系統、往來廠商 | 從官網、社群網站找出員工姓名和職稱 |
| ② **初始入侵** | 想辦法進入內網 | 寄**魚叉式釣魚郵件**給特定員工、利用對外系統的漏洞 |
| ③ **建立據點** | 在受害電腦安裝後門，和外部**中繼站（C2）**連線 | 植入遠端控制程式 |
| ④ **權限提升與橫向移動** | 取得管理員權限，從一台電腦擴散到其他主機 | 竊取網域管理員帳密、入侵檔案伺服器 |
| ⑤ **資料竊取** | 找出目標資料，壓縮加密後慢慢傳出去 | 把設計圖分批傳到外部 |
| ⑥ **長期潛伏、清除痕跡** | 刪除日誌、保留多個後門，持續監控 | 被清除一個後門，還有其他的 |

**寫法二：網路攻擊鏈（Cyber Kill Chain，Lockheed Martin 提出，七個階段）**

| 階段 | 英文 | 內容 |
|---|---|---|
| 1 偵察 | Reconnaissance | 蒐集目標資訊 |
| 2 武器化 | Weaponization | 製作攻擊工具（例如夾帶惡意程式的文件） |
| 3 遞送 | Delivery | 把武器送到目標（電子郵件、網站、USB） |
| 4 漏洞利用 | Exploitation | 觸發漏洞，執行惡意程式碼 |
| 5 安裝 | Installation | 安裝後門，取得持續存取 |
| 6 命令與控制 | Command & Control（C2） | 和攻擊者的伺服器建立連線，接受指令 |
| 7 目標行動 | Actions on Objectives | 竊取資料、破壞系統 |

💡 攻擊鏈的重點：**只要在任何一個階段把攻擊擋下來，整個攻擊就失敗**，所以防禦要分布在每個階段。

### 🎯 APT 的因應對策

依「**預防 → 偵測 → 應變**」分層作答：

| 層面 | 對策 |
|---|---|
| **預防** | ① **教育訓練**與社交工程演練，降低員工被釣魚的機率 ② 定期**修補漏洞**、關閉不必要的服務 ③ **最小權限**、管理員帳號多因子認證 ④ **網路分段**，關鍵系統和一般辦公網路隔離 ⑤ 落實**零信任**架構 |
| **偵測** | ① 部署**端點偵測與回應（EDR）** ② 建立**資安監控中心（SOC）**，用 **SIEM** 集中分析日誌 ③ 監控異常的對外連線（可能是 C2 通訊）和大量資料傳出 ④ 訂閱**威脅情資**，比對已知的攻擊特徵 |
| **應變** | ① 訂定**資安事件應變計畫**並定期演練 ② 依法**通報**（4-3 課）③ 隔離受害主機、保留跡證、全面清查後門 ④ 從離線備份還原（4-2 課）⑤ 事後檢討，改善防護 |

## 💼 工作實作

- **公司的 SOC 和 EDR**：辦公電腦上的端點防護軟體會回報異常行為給資安監控中心。收到資安單位詢問「你剛剛是不是執行了某某程式」時，要誠實回報
- **異常徵兆要通報**：電腦突然變慢、出現不明程式、帳號在你沒登入時有登入紀錄、收到同事寄來但內容奇怪的郵件，都要通報資安窗口
- **MITRE ATT&CK**：工作上分析攻擊時，資安人員常用 MITRE ATT&CK 框架，它把攻擊者的戰術和技術整理成矩陣，比攻擊鏈更細，可以用來檢查哪些攻擊技術目前偵測不到

## 📝 考古題示範

### 109 年：(一) 請說明 APT 攻擊之流程 (二) 請說明資訊管理人員對 APT 之因應對策

> 參考答案（自己寫的，不是官方答案）

**（一）APT 攻擊流程**

APT 是針對特定組織、長期潛伏的進階攻擊，流程可分為：
1. **情報蒐集**：調查目標組織的人員、系統與往來廠商
2. **初始入侵**：以魚叉式釣魚郵件或系統漏洞進入內網
3. **建立據點**：植入後門，與外部中繼站（C2）建立連線
4. **權限提升與橫向移動**：取得管理員權限，擴散到其他主機
5. **資料竊取**：找出機敏資料，加密後分批外傳
6. **長期潛伏**：清除痕跡、保留多個後門，持續監控

**（二）因應對策**
1. **預防**：員工教育訓練與社交工程演練、定期修補漏洞、最小權限與多因子認證、網路分段
2. **偵測**：部署 EDR、建立 SOC 以 SIEM 集中分析日誌、監控異常對外連線、運用威脅情資
3. **應變**：訂定並演練資安事件應變計畫、依法通報、隔離受害主機並保留跡證、從離線備份還原、事後檢討改善
