# 5-2 社交工程與商業電子郵件入侵（BEC） 🎯💼

> 對應考古題：115（BEC 常見攻擊手法、如何防範 BEC，14 分）

## 觀念

**社交工程（Social Engineering）**：不攻擊電腦，而是**攻擊人**。利用人性的弱點（信任、恐懼、貪心、急迫、好奇），騙人主動交出資料、點開連結、匯款。

再好的防火牆也擋不住員工自己把密碼告訴別人，所以社交工程常是 APT 的第一步（5-1 課）。

### 攻擊者利用的心理

| 心理 | 例子 |
|---|---|
| **權威** | 冒充老闆、主管機關、警察 |
| **急迫** | 「今天下班前一定要匯款」「帳號 24 小時內會被停用」 |
| **恐懼** | 「你的電腦中毒了」「你涉及洗錢案」 |
| **貪心** | 「你中獎了」「限時免費」 |
| **好奇** | 「年終獎金名單」「主管的薪資表」 |
| **信任** | 冒充熟悉的同事、往來廠商 |

## 🎯 常見的社交工程手法

| 手法 | 說明 |
|---|---|
| **網路釣魚**（Phishing） | 大量寄出假冒銀行、物流、網購平台的郵件，引導到假網站輸入帳密 |
| **魚叉式釣魚**（Spear Phishing） | **針對特定人或組織**量身打造的釣魚信，內容很逼真（例如提到真的專案名稱） |
| **鯨釣**（Whaling） | 鎖定**高階主管**的魚叉式釣魚 |
| **簡訊釣魚**（Smishing）／**電話詐騙**（Vishing） | 用簡訊或電話進行 |
| **假託**（Pretexting） | 編造情境取得信任，例如假裝是 IT 人員要求提供密碼「以便修電腦」 |
| **誘餌**（Baiting） | 故意在停車場丟下標著「薪資資料」的 USB 隨身碟，等人撿去插 |
| **尾隨**（Tailgating） | 跟在員工後面進入有門禁的區域 |

## 🎯 商業電子郵件入侵（BEC）

**BEC（Business Email Compromise）**：攻擊者**冒充或入侵**企業的電子郵件帳號（老闆、財務人員、往來廠商），以看似正常的商業往來信件，騙取**匯款**或**機敏資料**。

BEC 和一般釣魚的差別：

| | 一般釣魚 | BEC |
|---|---|---|
| 目標 | 大量、不特定對象 | **特定企業**的財務、會計、採購、高階主管 |
| 內容 | 常有連結或附件 | **通常沒有連結和附件**，只是文字要求，所以**防毒和郵件過濾很難擋** |
| 目的 | 竊取帳密、植入惡意程式 | **直接騙錢**（匯款到攻擊者帳戶）或騙資料 |
| 準備 | 少 | 事前長期蒐集情報，甚至先入侵信箱監看往來信件 |

### 🎯 BEC 常見攻擊手法

| 手法 | 情境 |
|---|---|
| **① 冒充高階主管（CEO 詐騙）** | 假冒總經理寫信給財務人員：「我正在談一筆機密併購，請立刻匯款到這個帳戶，不要告訴其他人」 |
| **② 假冒供應商、變更收款帳戶（假發票）** | 假冒長期往來的廠商：「我們的銀行帳戶變更了，這期貨款請匯到新帳戶」 |
| **③ 入侵真實信箱（帳號接管）** | 先用釣魚竊取員工或廠商的信箱密碼，登入後**監看往來信件**，在付款時機插入假的匯款指示；信件來自真實帳號，最難分辨 |
| **④ 冒充律師或主管機關** | 自稱律師或官員，以法律、保密為由施壓，要求緊急處理 |
| **⑤ 竊取資料** | 冒充主管向人資要員工個資、薪資資料，作為後續攻擊或詐騙用途 |

攻擊者常用的技巧：
- **相似網域**：`power.com.tw` 改成 `povver.com.tw`（w 換成 vv）、`company.com` 改成 `cornpany.com`（m 換成 rn）
- **偽造寄件者顯示名稱**：顯示名稱是「總經理 王大明」，實際寄件地址是外部免費信箱
- **設定信箱轉寄規則**：入侵信箱後偷偷設定規則，把特定信件轉寄出去或自動刪除，讓受害者看不到
- **製造急迫與保密**：要求「立刻處理」「不要告訴別人」，阻止受害者向其他人求證

### 🎯 如何防範 BEC

依「**技術、流程、人員**」三個層面作答：

| 層面 | 防範措施 |
|---|---|
| **技術** | ① 郵件伺服器設定 **SPF、DKIM、DMARC**，驗證寄件來源，擋下偽造的寄件網域 ② 所有信箱啟用**多因子認證**，避免帳號被接管 ③ 外部寄來的信件加上「**外部郵件**」標示 ④ 監控**相似網域**註冊和異常的轉寄規則、異常登入地點 ⑤ 使用郵件安全閘道過濾可疑信件 |
| **流程** | ① **匯款雙重確認**：收到匯款或**變更收款帳戶**的要求時，必須用**事先登記的電話**（不是信件上的電話）向對方確認 ② 大額匯款需要**多人核准**（職務區隔）③ 變更廠商帳戶要有正式的書面申請與審核程序 ④ 建立可疑信件的通報管道 |
| **人員** | ① 定期**教育訓練**，特別針對財務、採購、主管 ② 辦理**社交工程演練** ③ 建立「**遇到急迫、保密、改帳戶的要求，先停下來求證**」的文化，主管也要支持員工求證 |

### SPF、DKIM、DMARC 是什麼

| 機制 | 作用 | 比喻 |
|---|---|---|
| **SPF** | 公布「哪些郵件伺服器可以代表這個網域寄信」 | 公司公布「只有這幾位郵差能送我們的信」 |
| **DKIM** | 寄件伺服器對信件做**數位簽章**（4-4 課），收件端用 DNS 上的公鑰驗證信件沒被竄改 | 信封上蓋了公司的鋼印 |
| **DMARC** | 規定 SPF、DKIM 驗證失敗時要**怎麼處理**（不處理、隔離、拒收），並回報結果 | 告訴收件者「沒有鋼印的信請直接丟掉」 |

## 💼 工作實作

### 收到可疑信件的檢查清單

1. **看實際寄件地址**，不是只看顯示名稱；注意網域有沒有被換字
2. **滑鼠移到連結上**（不要點），看實際網址
3. 有沒有**急迫、保密、改帳戶、繞過正常流程**的要求？
4. 不確定就**用已知的電話或面對面**問本人，不要直接回信問（回信會回到攻擊者手上）
5. 透過公司規定的管道**通報**資安單位，即使已經點了也要立刻通報

### 社交工程演練

國營事業每年都會辦理社交工程演練：寄出模擬釣魚信，記錄誰開了信、誰點了連結、誰開了附件。
點了的人通常要補上教育訓練。演練的目的是**提升警覺**，不是抓人，被騙了要誠實通報。

## 📝 考古題示範

### 115 年：(一) BEC 常見攻擊手法？(二) 如何防範 BEC 攻擊？（每題 7 分）

> 參考答案（自己寫的，不是官方答案）

商業電子郵件入侵（BEC）是攻擊者冒充或入侵企業電子郵件帳號，以看似正常的商業往來信件，騙取匯款或機敏資料的社交工程攻擊。

**（一）常見攻擊手法**
1. **冒充高階主管**：假冒總經理，要求財務人員緊急且保密地匯款
2. **假冒供應商變更收款帳戶**：假冒往來廠商，通知「帳戶已變更」，騙取貨款
3. **入侵真實信箱**：竊取信箱密碼後監看往來信件，在付款時機插入假的匯款指示
4. **冒充律師或主管機關**：以法律或保密為由施壓，要求緊急處理
5. **竊取資料**：冒充主管向人資索取員工個資

常用技巧包括相似網域、偽造顯示名稱、設定隱藏的轉寄規則、製造急迫感。

**（二）防範方式**
1. **技術面**：設定 SPF、DKIM、DMARC 驗證寄件來源；信箱啟用多因子認證；外部郵件加註標示；監控相似網域與異常轉寄規則
2. **流程面**：匯款與變更收款帳戶須以事先登記的電話向對方確認；大額匯款多人核准；建立可疑信件通報管道
3. **人員面**：針對財務、採購與主管定期教育訓練，辦理社交工程演練，建立「先求證再處理」的文化
