# 6-2 機器學習與資料探勘 🎯💼

> 對應考古題：111（監督式學習與非監督式學習的定義、主要處理問題、常見演算法，15 分）、105（集群分析的意義與可能的應用）

## 觀念

| 名詞 | 意思 |
|---|---|
| **人工智慧**（AI） | 讓電腦表現出類似人類智慧的行為（最大的範圍） |
| **機器學習**（ML） | AI 的一種方法：**從資料中學習規律**，而不是由人寫死規則 |
| **深度學習**（DL） | 機器學習的一種：用**多層類神經網路**自動學習特徵，擅長影像、語音、文字 |
| **資料探勘**（Data Mining） | 從大量資料中**發掘**隱藏的、有價值的模式（常用機器學習的方法） |

```
  ┌─────────── 人工智慧 ───────────┐
  │   ┌──────── 機器學習 ────────┐  │
  │   │   ┌──── 深度學習 ────┐   │  │
  │   │   │                  │   │  │
  │   │   └──────────────────┘   │  │
  │   └──────────────────────────┘  │
  └─────────────────────────────────┘
```

傳統程式 vs 機器學習：
- **傳統程式**：規則 ＋ 資料 → 答案（人寫規則）
- **機器學習**：資料 ＋ 答案 → 規則（電腦學出規則，也就是「模型」）

## 🎯 三種學習方式

| | **監督式學習** | **非監督式學習** | **強化學習** |
|---|---|---|---|
| 訓練資料 | **有標籤**（有正確答案） | **沒有標籤** | 沒有標準答案，只有**獎勵或懲罰** |
| 目的 | 學會從輸入**預測**輸出 | 自己**發現資料的結構或規律** | 透過試誤，學會**得到最多獎勵的行動策略** |
| 比喻 | 老師給附答案的考古題練習 | 沒有答案，自己把東西分類 | 訓練寵物：做對給零食 |

### 🎯 監督式學習（Supervised Learning）

**定義**：用**有標籤**的訓練資料（每筆資料都有正確答案）訓練模型，讓模型學會輸入和輸出的對應關係，再用來**預測新資料**。

| 主要處理的問題 | 輸出 | 例子 |
|---|---|---|
| **分類**（Classification） | **類別** | 垃圾郵件判斷（是／否）、客戶會不會流失、影像辨識 |
| **迴歸**（Regression） | **連續數值** | 預測明天的用電量、房價、銷售額 |

常見演算法：

| 演算法 | 說明 |
|---|---|
| **線性迴歸** | 找出一條最符合資料的直線，預測數值 |
| **邏輯斯迴歸** | 名稱有迴歸，但用於**分類**，輸出屬於某類的機率 |
| **決策樹** | 用一連串「是／否」問題分類，容易解釋 |
| **隨機森林** | 很多棵決策樹投票，準確度較高 |
| **K 最近鄰**（KNN） | 看新資料最接近的 K 筆訓練資料多數屬於哪一類 |
| **支援向量機**（SVM） | 找出把兩類分開、間隔最大的邊界 |
| **單純貝氏**（Naive Bayes） | 用機率分類，常用於文字分類（垃圾郵件） |
| **類神經網路** | 模仿神經元的多層網路，深度學習的基礎 |

### 🎯 非監督式學習（Unsupervised Learning）

**定義**：訓練資料**沒有標籤**，由演算法自行從資料中找出**結構、群組或規律**。

| 主要處理的問題 | 說明 | 例子 |
|---|---|---|
| **集群**（Clustering） | 把相似的資料分成同一群 | 客戶分群、用電行為分群 |
| **關聯規則**（Association Rules） | 找出項目之間**一起出現**的規律 | 購物籃分析：買尿布的人常買啤酒 |
| **降維**（Dimensionality Reduction） | 把很多變數濃縮成少數幾個，保留主要資訊 | 主成分分析（PCA），方便視覺化 |
| **異常偵測**（Anomaly Detection） | 找出和大部分資料不同的點 | 竊電偵測、信用卡盜刷、設備異常 |

常見演算法：**K-means**、階層式集群、DBSCAN、**Apriori**（關聯規則）、PCA。

### 強化學習（Reinforcement Learning）

**代理人**（Agent）在**環境**中採取**行動**，根據得到的**獎勵**或**懲罰**調整策略，目標是長期累積最多獎勵。
例：AlphaGo 下圍棋、機器人學走路、自動調整空調以節能。

### 半監督式學習

只有**少量**資料有標籤、大量沒有標籤時，結合兩者。標籤很貴的時候常用（例如醫療影像要醫師標註）。

## 🎯 集群分析（Cluster Analysis，105 年題）

**意義**：一種**非監督式**學習方法，依資料之間的**相似度（距離）**，把資料分成數個群集，使**同一群內**的資料盡量相似、**不同群之間**盡量不同。事先不知道每筆資料屬於哪一群。

### K-means 演算法

1. 決定要分成 **K** 群，選 K 個初始**群中心**
2. 每筆資料分到**距離最近**的群中心
3. 重新計算每群的中心（**平均值**）
4. 重複 2、3，直到群中心不再改變

**例題**（改編自 112 年國營統計資訊類）：一維資料 10、25、45、55、80、90，分成 3 群，初始中心 0、40、100

| 次數 | 分群（依最近的中心） | 新的中心 |
|---|---|---|
| 第 1 次 | A：{10}；B：{25, 45, 55}；C：{80, 90} | A＝10、B＝(25＋45＋55)÷3 ≈ 41.67、C＝85 |
| 第 2 次 | A：{10, 25}；B：{45, 55}；C：{80, 90} | A＝17.5、B＝50、C＝85 |
| 第 3 次 | 分群和第 2 次相同 | 中心不變 → **收斂** |

（第 2 次：25 離 A 的中心 10 是 15，離 B 的中心 41.67 是 16.67，所以改分到 A。）

### 集群分析的應用

| 領域 | 應用 |
|---|---|
| **行銷** | **客戶分群**（依消費行為分成高價值、潛力、流失風險客戶），對不同群推不同方案 |
| **能源** | 依**用電行為**分群，設計不同電價方案；找出異常用電 |
| **金融** | 偵測異常交易（不屬於任何群的點） |
| **醫療** | 依症狀或基因資料將病患分群 |
| **影像** | 影像分割、壓縮 |

## 🎯 關聯規則（Association Rules）

找出「**買了 A 的人，也常買 B**」這類規則，寫成 **A → B**。三個指標：

| 指標 | 公式 | 意思 |
|---|---|---|
| **支持度**（Support） | 同時包含 A 和 B 的交易數 ÷ 總交易數 | 這個組合**多常出現** |
| **信賴度**（Confidence） | 同時包含 A 和 B 的交易數 ÷ 包含 A 的交易數 | 買了 A 的人，**有多少比例**也買 B |
| **增益**（Lift） | 信賴度 ÷ B 的支持度 | **> 1** 表示 A 和 B 正相關；= 1 表示無關；< 1 表示負相關 |

**例**：5 筆交易

| 交易 | 項目 |
|---|---|
| 1 | 牛奶、麵包 |
| 2 | 牛奶、尿布、啤酒、蛋 |
| 3 | 麵包、尿布、啤酒、可樂 |
| 4 | 牛奶、麵包、尿布、啤酒 |
| 5 | 牛奶、麵包、尿布、可樂 |

規則 **{尿布} → {啤酒}**：
- 支持度 ＝ 3 ÷ 5 ＝ **0.6**（交易 2、3、4 同時有尿布和啤酒）
- 信賴度 ＝ 3 ÷ 4 ＝ **0.75**（4 筆有尿布，其中 3 筆有啤酒）
- 增益 ＝ 0.75 ÷ (3 ÷ 5) ＝ **1.25** > 1，正相關

**Apriori 演算法**：先設定**最小支持度**，只保留常出現的項目組合（頻繁項目集），再從中產生規則。核心原理：**如果一個項目集不頻繁，它的超集合也一定不頻繁**，所以可以提早排除，減少計算量。

## 💼 工作實作

- **國營事業的應用**：用電或用水量**預測**（迴歸）、設備**故障預測**（分類）、**用戶分群**（集群）、**異常用電偵測**（異常偵測）
- **先確定問題類型再選方法**：有歷史答案要預測 → 監督式；沒有答案、想找規律 → 非監督式
- **工具**：Python 的 scikit-learn（傳統機器學習）、pandas（資料處理）；不寫程式的話，Excel、Power BI 也有基本的預測和分群功能
- **資料比演算法重要**：資料品質不好、沒有代表性，換什麼演算法都沒用

### 105 年：請簡述巨量資料分析中集群分析之意義及其可能之應用

> 參考答案（自己寫的，不是官方答案）

**意義**：集群分析是一種非監督式學習方法，在事先不知道資料類別的情況下，依資料間的相似度（如距離）將資料分成數個群集，使同群內資料盡量相似、不同群間盡量相異。常見演算法如 K-means，先選定 K 個群中心，將資料分到最近的中心，再重新計算中心，反覆至收斂。

**應用**：
1. **客戶分群**：依消費行為將客戶分群，進行精準行銷
2. **用電行為分析**：依用電型態分群，設計電價方案或偵測異常用電
3. **異常偵測**：不屬於任何群集的資料可能是詐欺或故障
4. **醫療**：依症狀或基因資料將病患分群
5. **影像處理**：影像分割與壓縮
