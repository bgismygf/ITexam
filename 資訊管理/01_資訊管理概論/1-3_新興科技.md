# 1-3 新興科技：物聯網、區塊鏈、推播技術 🎯

> 對應考古題：110（物聯網技術涵蓋的 4 項範疇，5 分）、109（解釋名詞：推播技術、區塊鏈，各約 5 分）
> 雲端運算見第 2 單元，巨量資料和 AI 見第 6 單元。

## 🎯 物聯網（IoT，Internet of Things）

**物聯網**：讓各種「物品」（感測器、設備、家電、車輛）**連上網路**，自動蒐集資料、互相溝通，並根據資料做出反應或提供服務。

### 🎯 四層架構（110 年題：4 項範疇）

由下而上：

```
  ┌───────────────────────────────────────────┐
  │ ④ 應用服務層：提供給使用者的服務            │  智慧電網、智慧醫療、智慧交通
  ├───────────────────────────────────────────┤
  │ ③ 平台工具層：處理、分析資料的軟體平台      │  雲端平台、巨量資料、AI 分析
  ├───────────────────────────────────────────┤
  │ ② 網路連接層：把資料傳出去                  │  Wi-Fi、4G/5G、NB-IoT、LoRa
  ├───────────────────────────────────────────┤
  │ ① 感知裝置層：感測、辨識、蒐集資料          │  感測器、RFID、GPS、攝影機
  └───────────────────────────────────────────┘
```

| 層 | 說明 | 技術與例子 |
|---|---|---|
| **① 感知裝置層**（感測層，Device） | 用感測器和辨識設備**蒐集環境和物品的資料** | 溫度、濕度、壓力、光線感測器；RFID 標籤與讀取器；GPS；攝影機 |
| **② 網路連接層**（網路層，Connect） | 把感知層的資料**可靠、安全地傳送**到平台 | Wi-Fi、藍牙、Zigbee、4G／5G、低功耗廣域網路（NB-IoT、LoRa） |
| **③ 平台工具層**（Platform） | **儲存、處理、分析**資料的軟體平台，作為網路層和應用層的介面 | 雲端平台、巨量資料分析、人工智慧、資安防護 |
| **④ 應用服務層**（Application） | 依需求把資料加值後，**提供給使用者**的服務 | 智慧電表、智慧家庭、智慧工廠、遠距醫療、車聯網 |

⚠️ 很多教科書用**三層架構**：感知層、網路層、應用層。四層架構是把應用層再分成「平台工具層」和「應用服務層」。題目問 4 項就寫四層，問 3 層就寫三層。

### 物聯網的資安風險

- 設備數量多、運算能力低，難以安裝防毒或加密
- 常使用**預設密碼**（5-4 課），而且很少更新韌體
- 被入侵後可能變成殭屍網路的一員，發動 DDoS（5-1 課）
- 用在關鍵基礎設施（例如電網）時，被入侵可能影響民生

### 相關技術

| 技術 | 說明 |
|---|---|
| **邊緣運算**（Edge Computing） | 在靠近資料來源的地方（設備或閘道器）先處理資料，降低延遲和傳輸量，不必全部送到雲端 |
| **數位孿生**（Digital Twin） | 在電腦中建立實體設備的虛擬複製品，用即時資料模擬、預測和最佳化 |
| **工業物聯網**（IIoT） | 物聯網用在工廠和工業設備，例如預測性維修 |

## 🎯 區塊鏈（Blockchain）

**區塊鏈**：一種**分散式帳本**技術。交易資料打包成「區塊」，每個區塊記錄前一個區塊的**雜湊值**，串成一條鏈，由網路上的多個節點**共同保存和驗證**，資料**難以竄改**。

```
 ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
 │ 區塊 1        │    │ 區塊 2        │    │ 區塊 3        │
 │ 前一區塊雜湊：0│◄───│ 前一區塊雜湊：H1│◄───│ 前一區塊雜湊：H2│
 │ 交易資料       │    │ 交易資料       │    │ 交易資料       │
 │ 本區塊雜湊：H1 │    │ 本區塊雜湊：H2 │    │ 本區塊雜湊：H3 │
 └──────────────┘    └──────────────┘    └──────────────┘
   修改區塊 1 的資料 → H1 改變 → 區塊 2 記錄的 H1 對不上 → 後面整條鏈都要重算，而且其他節點不會接受
```

### 特性

| 特性 | 說明 |
|---|---|
| **去中心化** | 沒有單一管理者，由多個節點共同維護 |
| **不可竄改** | 每個區塊用雜湊值（4-4 課）串起來，改一個區塊會連帶影響後面所有區塊 |
| **透明可追溯** | 所有交易紀錄都保留，可以追查完整歷史 |
| **共識機制** | 節點之間用規則決定哪筆交易有效，例如**工作量證明（PoW）**、**權益證明（PoS）** |
| **智慧合約**（Smart Contract） | 寫在區塊鏈上的程式，條件達成時**自動執行**，例如貨到自動付款 |

### 種類

| 種類 | 誰能參與 | 例子 |
|---|---|---|
| **公有鏈** | 任何人 | 比特幣、以太坊 |
| **私有鏈** | 單一組織內部 | 企業內部的文件存證 |
| **聯盟鏈** | 經過授權的多個組織 | 銀行間的清算、供應鏈夥伴共享 |

### 應用

加密貨幣、供應鏈溯源（農產品產銷履歷）、文件和學歷證書存證、綠電憑證交易、跨境支付。

### 限制

交易速度較慢、公有鏈（PoW）耗電量大、上鏈的資料錯了很難修改（「垃圾進、垃圾出」）、法規還在發展中。

## 🎯 推播技術（Push Technology）

**推播技術**：由**伺服器主動**把資訊傳送給使用者，使用者不必自己去查詢。

| 方式 | 誰發起 | 例子 |
|---|---|---|
| **拉取**（Pull） | **使用者**主動要求 | 開瀏覽器查天氣、重新整理信箱 |
| **推播**（Push） | **伺服器**主動送出 | 手機 App 通知、地震警報、新聞快訊、帳單到期提醒 |

### 常見技術

- **行動推播服務**：Apple 的 APNs、Google 的 FCM，App 伺服器透過它們把通知送到手機
- **WebSocket**：瀏覽器和伺服器建立長時間的雙向連線，伺服器可以隨時傳資料過來（例如即時聊天、股價）
- **電子郵件、簡訊通知**

### 優缺點

| 優點 | 缺點 |
|---|---|
| **即時**：重要資訊立刻送達 | 推播太多會**打擾使用者**，被關閉通知 |
| 使用者不必一直查詢 | 涉及**個資與隱私**，要取得使用者同意 |
| 提高使用者互動和回訪 | 推播內容可能被偽造，成為釣魚管道 |

## 💼 工作實作

- **國營事業的物聯網應用**：智慧電表（AMI）、智慧水表、變電所和管線的感測監控、發電機組的預測性維修。新進人員可能參與這類系統的資料分析或維運
- **物聯網設備的資安**：管理感測設備時，第一件事是**改掉預設密碼**、確認韌體有更新、把設備放在獨立的網段
- **推播的實務**：停電、停水通知會用簡訊或 App 推播；發送前要確認名單正確，避免大量誤發

## 📝 考古題示範

### 110 年：請說明物聯網（IoT）技術涵蓋的 4 項範疇（5 分）

> 參考答案（自己寫的，不是官方答案）

物聯網架構由下而上可分為四層：
1. **感知裝置層**：以感測器、RFID、GPS 等裝置感測與辨識環境及物品資料
2. **網路連接層**：透過 Wi-Fi、行動通訊、NB-IoT 等網路，將資料可靠且安全地傳送
3. **平台工具層**：以雲端平台、巨量資料、人工智慧等技術儲存、處理與分析資料
4. **應用服務層**：將分析後的資訊加值，提供智慧電網、智慧醫療、智慧交通等服務

### 109 年：解釋名詞：推播技術、區塊鏈

> 參考答案（自己寫的，不是官方答案）

**推播技術**：由伺服器主動將資訊傳送給使用者的技術，相對於使用者主動查詢的拉取（Pull）方式。例如手機 App 通知、地震警報。優點是即時，但推播過多會干擾使用者。

**區塊鏈**：一種分散式帳本技術。交易資料打包成區塊，每個區塊包含前一區塊的雜湊值而串成鏈，由多個節點透過共識機制共同驗證與保存，具有去中心化、不可竄改、可追溯的特性，可應用於加密貨幣、供應鏈溯源、文件存證等。
