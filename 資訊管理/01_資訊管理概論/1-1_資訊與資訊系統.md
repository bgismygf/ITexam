# 1-1 資訊與資訊系統 🎯💼

> 對應考古題：110（資訊系統包含硬體、軟體、資料、程序及人員等 5 項元件）

## 觀念

**資訊管理**：運用資訊科技，有效地蒐集、處理、儲存和傳遞資訊，以支援組織的**作業、管理和決策**。
這一課先建立三個基本觀念：什麼是資訊、資訊系統由什麼組成、組織裡有哪些資訊系統。

## 🎯 資料、資訊、知識、智慧（DIKW）

| 層次 | 意思 | 例子 |
|---|---|---|
| **資料**（Data） | 未經處理的原始事實、數字、符號 | 「2025/3/1、A 產品、120 台」 |
| **資訊**（Information） | 資料經過**整理、處理**，對使用者**有意義** | 「A 產品 3 月銷量比 2 月成長 20%」 |
| **知識**（Knowledge） | 從資訊中歸納出的**經驗、規則**，能用來解決問題 | 「每年 3 月開學季，A 產品銷量都會成長，要提前備貨」 |
| **智慧**（Wisdom） | 運用知識做出**正確判斷**，知道為什麼、何時該怎麼做 | 「考量市場趨勢，明年應該把 A 產品轉型成訂閱制」 |

```
     智慧（為什麼、該怎麼做）
       ▲
     知識（如何做）
       ▲
     資訊（是什麼、有意義）
       ▲
     資料（原始事實）
```

💡 同一筆東西對不同人可能是資料或資訊：銷售明細對店員是資訊，對總經理只是資料，要彙整成報表才有意義。

### 好資訊的特性

| 特性 | 意思 |
|---|---|
| **正確性** | 沒有錯誤 |
| **及時性** | 需要時就拿得到，過期的資訊沒有價值 |
| **完整性** | 決策需要的內容都有 |
| **攸關性** | 和要做的決策有關 |
| **精簡性** | 不多不少，重點清楚 |

## 🎯 資訊系統的五元件（110 年題）

| 元件 | 說明 | 例子 |
|---|---|---|
| **硬體**（Hardware） | 處理、儲存、傳輸資料的實體設備 | 伺服器、電腦、網路設備、儲存設備 |
| **軟體**（Software） | 指揮硬體運作的程式 | 作業系統、資料庫管理系統、應用程式 |
| **資料**（Data） | 系統處理的事實與數字，是組織的重要資產 | 客戶資料、交易紀錄 |
| **程序**（Procedure） | 使用和操作系統的規則、步驟與政策 | 作業手冊、標準作業程序（SOP）、備份程序 |
| **人員**（People） | 使用、操作、維護系統的人 | 使用者、系統管理者、程式設計師 |

💡 **記法**：硬體和軟體是「機器」，資料是「原料」，程序是「規則」，人員是「操作的人」。
**人員**常被認為是資訊系統中最重要、也是**資安最弱**的一環（5-2 課的社交工程就是攻擊人員）。

110 年題目接著問「硬體及軟體可藉由 5 個資訊技術防護措施進行安全防護」，答案在 [4-1 課](../04_資訊安全管理/4-1_資安特性與防護措施.md)。

## 🎯 組織中的資訊系統

### 依管理層級（Anthony 的管理金字塔）

```
          ┌──────────┐
          │ 策略層    │  高階主管：長期規劃、非結構化決策  → EIS／ESS
          ├──────────┤
          │ 管理層    │  中階主管：監控、控制、半結構化決策 → MIS、DSS
          ├──────────┤
          │ 作業層    │  基層人員：日常交易、結構化決策    → TPS
          └──────────┘
```

| 系統 | 全名 | 使用者 | 功能 | 例子 |
|---|---|---|---|---|
| **TPS** | 交易處理系統（Transaction Processing System） | 基層人員 | 記錄和處理**日常例行交易**，是其他系統的資料來源 | 收銀系統、訂單輸入、薪資計算 |
| **MIS** | 管理資訊系統（Management Information System） | 中階主管 | 彙整 TPS 的資料，產生**定期報表**，用於監控和控制 | 每月銷售報表、預算執行報表 |
| **DSS** | 決策支援系統（Decision Support System） | 中階主管、分析人員 | 用**模型和分析工具**支援**半結構化**決策，可以做「如果…會怎樣」（What-if）分析 | 定價模擬、排程最佳化 |
| **EIS／ESS** | 主管資訊系統（Executive Information／Support System） | 高階主管 | 以**儀表板**呈現整體績效和外部資訊，可以往下鑽取細節，支援策略決策 | 經營儀表板 |
| **KMS** | 知識管理系統（Knowledge Management System） | 全體員工 | 蒐集、分享組織的知識和經驗 | 內部知識庫、FAQ、文件管理 |

### 決策的結構化程度

| 類型 | 特徵 | 例子 | 支援系統 |
|---|---|---|---|
| **結構化** | 步驟固定、有明確規則，可以自動化 | 庫存低於安全量就補貨 | TPS |
| **半結構化** | 部分有規則，部分要靠判斷 | 決定促銷預算 | DSS |
| **非結構化** | 沒有固定規則，靠經驗和直覺 | 要不要進入新市場 | EIS |

### 🎯 企業系統（跨部門整合）

| 系統 | 全名 | 整合什麼 | 效益 |
|---|---|---|---|
| **ERP** | 企業資源規劃（Enterprise Resource Planning） | **企業內部**各部門：財務、人事、生產、採購、庫存 | 資料只輸入一次、各部門共用，打破部門間的資料隔閡（1-2 課數據孤島） |
| **CRM** | 顧客關係管理（Customer Relationship Management） | 和**顧客**的所有接觸：銷售、行銷、客服 | 了解顧客、提高滿意度與忠誠度 |
| **SCM** | 供應鏈管理（Supply Chain Management） | 和**上下游**（供應商、物流、經銷商）的流程 | 降低庫存、縮短交期 |

💡 **記法**：ERP 往**內**整合，CRM 往**下游顧客**，SCM 往**上下游夥伴**。

## 💼 工作實作

國營事業常見的資訊系統：

| 系統 | 類型 | 例子 |
|---|---|---|
| 電費、水費、油品的收費和帳務系統 | TPS | 每天處理大量用戶交易 |
| 財務、人事、採購、物料系統 | ERP | 常見的商用 ERP 產品有 SAP、Oracle 等 |
| 客服中心、用戶服務系統 | CRM | 停電通報、帳單查詢 |
| 經營管理儀表板 | EIS | 給主管看的發電量、營收、異常指標 |
| 公文系統、知識庫 | KMS | 承辦經驗、作業手冊 |

新進人員常被指派**系統管理員**或**業務窗口**，要能說清楚自己負責的系統屬於哪一類、資料從哪裡來、給誰用，和廠商或其他部門溝通時才不會雞同鴨講。

## 📝 考古題示範

### 110 年第一題前半：資訊系統包含哪 5 項元件

> 參考答案（自己寫的，不是官方答案）

資訊系統由五項元件組成：
1. **硬體**：處理、儲存與傳輸資料的實體設備，如伺服器、個人電腦、網路設備
2. **軟體**：指揮硬體運作的程式，如作業系統、資料庫管理系統、應用程式
3. **資料**：系統處理的事實與數字，是組織的重要資產
4. **程序**：使用與操作系統的規則與步驟，如標準作業程序、備份程序
5. **人員**：使用、操作與維護系統的人，如使用者與資訊人員

（硬體與軟體的 5 個技術防護措施，見 4-1 課的示範答案。）
