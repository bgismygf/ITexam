# 資訊管理教材

目標：
1. **考試**：國營聯招資訊類科目 B 的「資訊管理」（申論題）
2. **工作**：能判斷資安風險、規劃雲端與系統導入、和廠商或開發團隊溝通

📘 完整課綱（考古題分析、每課對應的考題、優先順序）請看 [課綱.md](課綱.md)

## 怎麼使用

每課只有 `.md` 講義，在 VS Code 打開後按 `Ctrl+Shift+V` 顯示排版後的畫面。每課包含：

| 段落 | 內容 |
|---|---|
| 觀念 | 白話說明 |
| 🎯 考試重點 | 可以直接寫在答案卷上的條列、分類、圖 |
| 💼 工作實作 | 進入職場後會遇到的做法和情境 |
| 📝 考古題示範 | 對應考題的參考答案（**自己寫的，不是官方答案**） |
| 小測驗 | 附答案 |

**申論題的練習方式**：先看題目、自己在紙上寫答案（計時），再對照「考古題示範」，看漏了哪些重點。
