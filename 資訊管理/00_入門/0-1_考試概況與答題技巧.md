# 0-1 考試概況與申論題答題技巧 🎯

> 依國營聯招科目 B 111～115 年考卷整理。考試規定以當年度簡章為準。

## 考試概況

| 項目 | 內容 |
|---|---|
| 科目 | 專業科目 B：**資訊管理＋程式設計**（同一張考卷） |

|---|---|---|

| 112 | SQL 15、數位轉型 15、雲端資安指引 20 ＝ **50 分** | 緩衝區溢位（資安）、堆疊、資料清理程式 |
| 113 | 資料庫 16、雲端＋PDCA 18、UML 16 ＝ **50 分** | 樹、插入排序、因數程式 |
| 114 | traceroute 25、DNS 安全 15、IPv6 10 ＝ **50 分** | 快樂數、Java、Web 攻擊（資安） |
| 115 | BEC 14、數據孤島 18、AI 工程 18 ＝ **50 分** | C 程式追蹤、Min-Heap、連續天數程式 |

**觀察**：
- 前三題約 **50 分**是資訊管理（含資料庫），後三題是程式設計
- 程式設計的部分也常出**資安題**（112 緩衝區溢位、114 Web 攻擊），所以資安的分數其實更多
- 資訊管理每題 **14～25 分**，一題寫不好影響很大

## 🎯 申論題答題技巧

### 1. 標準架構：定義 → 分點 → 舉例 →（畫圖）→ 結論

以「請說明何謂數據孤島」為例：

```
（一）定義：一句話說清楚是什麼
     數據孤島是指組織內各部門的資料分散在不同系統中，彼此無法流通整合……

（二）分點說明：用編號條列，每點一個重點，先寫關鍵詞再解釋
     1. 系統各自建置：……
     2. 資料標準不一致：……

（三）舉例：舉一個實際的例子
     例如業務部用 CRM、財務部用 ERP，客戶資料兩邊不一致……

（四）結論（可省略）：一兩句收尾
```

### 2. 「請列舉 N 項」：剛好寫 N 項，不要少也不必多

- 題目說「5 項」，就寫**剛好 5 項**，用 1. 2. 3. 4. 5. 編號，閱卷老師一眼就能算分
- 每項先寫**粗體關鍵詞**，再用一兩句話解釋
- 如果題目引用特定文件（例如「依據○○參考指引」），要用**文件原本的分類和用詞**（4-3、5-4、2-2 課有整理）
- 不確定哪 N 項是標準答案時，選最有把握的 N 項，不要寫一大堆讓老師自己挑

### 3. 會畫圖就畫圖

題目寫「**繪圖說明**」「**畫出示意圖**」時，**沒有圖會被大量扣分**。題目沒要求，但有圖比較清楚的（例如流程、架構），畫一張簡單的圖也會加分。

常考的圖：

| 圖 | 課 |
|---|---|
| PDCA 循環 | 4-2 |
| UML（使用案例圖、類別圖、循序圖、活動圖） | 3-2 |
| AOV／AOE 網路、要徑 | 3-5 |
| 大數據平台架構（資料來源 → 資料系統 → 資料應用） | 6-1 |
| 雲端服務模式的責任分層 | 2-1 |

畫圖要點：**方框＋箭頭＋標示文字**就夠了，不用畫得漂亮，但每個元素都要標名稱。

### 4. 比較題用表格

「請比較 A 與 B」「說明 IPv4 與 IPv6 之異同」，**直接畫表格**：第一欄是比較項目，後面每欄一個比較對象。表格比文字清楚，也不容易漏項。

### 5. 時間分配

120 分鐘、100 分，平均**每分約 1.2 分鐘**：

| 配分 | 建議時間 |
|---|---|
| 5 分的小題 | 6 分鐘 |
| 15 分的大題 | 18 分鐘 |
| 20 分的大題 | 24 分鐘 |

- 先寫**最有把握**的題目，不要卡在一題
- 程式題通常比較花時間，要預留
- 最後 5 分鐘檢查題號有沒有寫錯、有沒有漏答小題

### 6. 答案卷的格式

- 每大題**寫明題號**，小題也要編號，例如「一、（一）」
- 段落之間空一行，不要寫成一整坨
- 字寫清楚，專有名詞可以寫英文（例如 CIA、SSDLC）

### 7. 時事題的準備

近年題目常跟著產業趨勢：數位轉型（112）、數據孤島與 AI 工程（115）。準備方法：
- 考前三個月注意 iThome、數位時代等科技媒體的熱門議題
- 注意**政府資安政策**（數位發展部、資通安全署、國家資通安全研究院）的新文件
- 遇到沒看過的名詞，從**字面意思＋相關的已知概念**推論作答，不要空白

## 💼 工作實作

申論題的寫法和職場上寫**簽呈、報告、提案**是一樣的：
- 先講結論或定義，再分點說明理由
- 比較方案時用表格列出優缺點
- 有流程、架構時附圖

考試練習的寫作方式，進入國營事業後會直接用在公文和報告上。

## 本教材的使用方式

1. 每課讀完觀念和 🎯 考試重點
2. 看「📝 考古題示範」之前，**先自己在紙上寫答案**，計時
3. 對照示範答案，找出漏掉的重點
4. 考前一個月，用 `考古題/資訊管理、程式設計/` 的整份考卷做**限時模擬**（120 分鐘）
